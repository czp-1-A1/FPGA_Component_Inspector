# PH1P35芯片与MIPI资料说明

## 1. 这个目录是干什么的

本目录主要解决以下问题：

- SC500 摄像头的 MIPI 数据怎样进入 FPGA；
- PH1P35 是否有足够的逻辑、存储器、DSP 和时钟资源；
- 外接电路应使用什么 IO 电平和接口；
- 项目报告中如何说明选择 PH1P35 的理由。

这些文件属于芯片和接口的参考手册，不是载带检测算法教程。开发时不需要从头读到尾，遇到对应问题时查询即可。

## 2. 文件作用

### 2.1 `UG1316_安路科技PH1P系列FPGA MIPI用户手册.pdf`

**重要程度：核心资料。**

主要用于了解 PH1P 系列 FPGA 内部 MIPI D-PHY 硬核的使用方法，包括：

- MIPI 接收端的时钟通道和数据通道；
- Lane 数量和接口信号；
- MIPI 硬核输入、输出端口；
- 接收时钟、复位和配置方法；
- MIPI 数据无法接收时的排查依据。

在本项目中，它对应：

`SC500摄像头 → MIPI接收 → RAW10图像数据`

第一阶段直接运行官方 MIPI-HDMI 例程时不必通读。如果出现无画面、数据不稳定、MIPI 锁定失败或需要修改接收配置，应重点查阅该手册。

### 2.2 `DS1300_PH1P_Datasheet.pdf`

**重要程度：核心资料。**

这是 PH1P 系列的详细数据手册，主要用于查询：

- PH1P35 的逻辑单元、触发器、片上存储器和 DSP 资源；
- PLL、系统时钟和各类时钟资源；
- IO Bank、接口标准和电气参数；
- MIPI、DDR 等硬件能力；
- 芯片封装、引脚和工作条件。

在本项目中主要用于：

- 估算图像缓存、行缓存和检测模块能否放入 PH1P35；
- 规划定位孔检测、元件检测、OSD 和运动跟踪模块的资源；
- 排查综合后资源不足或布局布线时序不通过的问题；
- 核对扩展 IO 的电平兼容性；
- 编写 FPGA 资源和器件选型分析。

注意：最终资源是否足够，应以 TD 工具生成的综合和布局布线报告为准，不能只靠手册估算。

### 2.3 `DS1301_PH1P_FamilyOverview.pdf`

**重要程度：辅助资料。**

这是 PH1P 系列的快速概览，适合了解：

- PH1P 系列总体架构；
- 不同型号之间的资源差异；
- 系列支持的主要接口和应用方向。

本项目已经确定使用 PH1P35，因此它对代码开发帮助不大，主要用于项目总体分析、器件选型说明和答辩材料。

### 2.4 `安路选型手册_202503.pdf`

**重要程度：报告备用资料。**

主要用于比较安路不同 FPGA 产品系列，说明为什么比赛开发板上的 PH1P35 适合本项目。

可用于支撑以下选型理由：

- 具备摄像头所需的 MIPI 接口能力；
- 可以连接 DDR2 完成图像帧缓存；
- 具有足够的逻辑、片上存储和 DSP 资源构建流式视觉处理链路；
- 支持 HDMI 显示和多路扩展 IO；
- 能够同时完成图像检测、画面标注和送料机构控制。

该文件不需要在算法开发阶段频繁查阅。

### 2.5 `参考IP设计资料文档`（已解压目录）

**重要程度：按需使用。**

该目录是 `参考IP设计资料文档.zip` 的解压内容，包含官方 IP 手册和部分参考工程：

| 资料 | 对本项目的作用 | 使用建议 |
|---|---|---|
| `IPUG012_Soft_FIFO用户手册_v3.0.pdf` | 视频流级间缓冲、跨模块解耦、缺陷事件 FIFO 和运动跟踪队列 | **比较有用，建议保留** |
| `IPUG035_安路PH1A系列FPGA DDR IP用户手册.pdf` | 了解 DDR IP 接口和配置思路 | Lab 1 的 DDR2 链路异常时参考；它标注为 PH1A，不能直接当作 PH1P35 配置依据 |
| `UG921_安路科技PH1A系列FPGA MIPI DPHY-RX用户手册.pdf` | 补充了解旧系列 MIPI RX 结构 | 只作辅助，PH1P35 应优先使用本目录的 UG1316 |
| `APUG092_HDMI1.4b_Transmitter_V1.0` | HDMI 发送参考工程、约束和 HDL 代码 | Lab 1/Lab 3 已有显示链路，只有需要重构 HDMI 输出时再看 |
| `APUG010_Local bus总线的SDRAM读写v1.1.pdf` | SDRAM 读写和总线控制参考 | 与当前 DDR2 图像缓存不完全相同，作为控制思路备用 |
| `APUG011_基于ERAM接口实现的高性能SDRAM读写v1.2.pdf` | ERAM 接口和 SDRAM 高速读写参考 | 当前阶段优先级较低 |
| `APUG013_UDP_Communication_Protocol_Reference_Design_v1.5` | UDP 网络通信参考工程 | 当前作品没有网络传输需求，暂时不用；以后扩展远程统计时再考虑 |

对当前工程最有价值的是 **Soft FIFO**。它可以用于保存缺陷穴位编号、缺陷类型和距处置位置的孔位数，也可以用于视频处理模块之间的数据缓冲。DDR、MIPI 和 HDMI 资料主要作为官方比赛例程出现问题时的补充参考。

## 4. 推荐使用顺序

1. 先运行官方 Lab 1，打通 `SC500 → MIPI → DDR2 → HDMI`。
2. 摄像头无画面或 MIPI 数据异常时，查 MIPI 用户手册。
3. 加入定位孔、元件检测和 OSD 模块后，查看 TD 综合报告。
4. 出现资源不足、时序不通过或 IO 电平问题时，查 PH1P 数据手册。
5. 编写项目报告和答辩材料时，再使用系列概览和选型手册。

## 5. 当前结论

这个目录需要保留，但不需要全部通读：

- **开发核心：** MIPI 用户手册、PH1P 数据手册；

真正搭建工程时，应以官方三个实验工程为代码基础，以本目录资料作为配置、资源评估和故障排查依据。
