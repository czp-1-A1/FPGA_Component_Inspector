# 当前帧穴位/定位孔角色合同

`tb_pocket_row_contract.sv`检查当前帧测量、取消/复位、不合法位置和缺少亮证据等13个完整RGB场景。

`tb_tail_29_plus_7_rgb.sv`输入合成29穴（22正常、6空、1复核）及7个6像素全空穴。它在报警后由外部继续推进图像，用于独立核对完整36穴；同时要求首次报警为总号34。此测试不声称报警后电机仍送料。

`tb_small_tail_closed_loop.sv`按实际feed输出决定图像移动，输入7个小空孔且无有件参考，第五空穴必须停止并保持报警，末尾两穴不计入已检总数。

`tb_pocket_row_phases.sv`保留原8组独立横纵采样相位目标，并加入弱定位孔/小空孔组合4组与只有定位孔4组负例。旧r0第7组失败日志保留；最终r1必须在同一期望下通过。`tb_pocket_row_phase_trace.sv`是同一旧失败的诊断版本。

`tb_pocket_row_native.sv`来自原12RAW相机链路合同，仅增加POCKET_ROW_ROLES=1和更换模块名；原像素/计数/时间/显示断言不变，派生清单见derivation.json。

所有输入先冻结再运行；不使用手机视频透视画面充当原生传感器回放，不把旧失败或未分类边界计为通过。软件断言与实板验收分开记录。
