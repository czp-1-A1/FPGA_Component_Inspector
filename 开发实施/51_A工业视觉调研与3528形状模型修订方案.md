# 工业视觉调研与3528形状模型修订方案

检索日期：2026-10-13。用户要求查工业方法并借鉴，当前仍只处理3528白色器件。本轮为调研和修订方案，不代表形状模型、模板库或新bit已经实现。

## 必须修正的结论

最新现场照片中，固定青框圈住送料定位孔，GRAY和EDGE同时输出有件。MEAN79，EC十六进制033A=826，GS十六进制03580A=219146；三个旧门限条件均成立，但被测对象错误。

这不是单纯调门限能闭环的问题。当前MEAN、EC、GS没有保留足够的空间形状信息；灰度与边缘两个旧类别一致，也不能证明是器件。仅恢复左右黑带背景检查同样不足，因为送料定位孔两侧也是黑带。Sobel轮廓提取在工作，缺少的是后面的目标识别/模型比对层。

因此修正50计划的优先级：**背景检查只作辅助；3528的形状约束或轻量模板进入下一版必需的识别设计。** 不再将“灰度越亮越有件”或“边缘越多越有件”当作正式检测方案。

## 查到的工业方法（官方原始资料）

1. **教导模型后做几何匹配。** Cognex PatMax学习边界特征及其空间关系，可以屏蔽训练图中易变的区域。这里的模型可以是一组几何特征，不一定是整张图片数据库。[Cognex PatMax官方文档](https://docs.cognex.com/vpro_0x090a00/web/en/help/html/89fbd2bc-12b5-4287-adfc-156b10859424.htm)
2. **区域分析也用于存在检测。** KEYENCE介绍二值分割、区域数量、面积及位置等分析，并提供注册标准目标后搜索的另一条路线。这说明工业方法不限定为每个型号一张完整边缘图。[KEYENCE存在检测原理](https://www.keyence.com/ss/products/vision/visionbasics/use/inspection01/)
3. **位置校正与后续检查分开。** KEYENCE说明利用参考特征估计偏移/转角，再更新后续检查的坐标，而不是始终在固定屏幕坐标比较。[KEYENCE位置校正说明](https://www.keyence.com/products/vision/applications/position-correction-in-vision-systems-a-core-function-for-stable-inspection-and-measurement.jsp)
4. **限制搜索并输出匹配结果。** HALCON形状匹配接口使用已建立的模型，支持限定图像搜索域和旋转范围，返回位置、角度和得分。[MVTec HALCON 25.05形状匹配算子](https://www.mvtec.com/doc/halcon/2505/en/find_shape_model.html)
5. **载带设备确实区分穴内状态。** Exatron的编带设备提供穴内视觉检查选项，包括空穴/出穴和翻转等项目。该产品页能证明工业应用的检查对象，但没有公开具体算法，不能据此认定全部设备使用某种模板。[Exatron编带设备官方说明](https://www.exatron.com/product/model-1010-manual-tape-and-reel/)

以上是方法与接口资料，不是对本项目准确率的背书。下列结构是针对本项目的工程建议，不是厂商给出的统一工业标准。

## 适合本项目的模型/配方

先为3528建立一份配方，内容至少区分：

| 内容 | 作用 |
|---|---|
| 载带/真正穴位的参考结构 | 建立检测位置和方向；送料孔只可作参考，不是器件 |
| 正常3528的稳定外形 | 记录白色主体、外形宽高/比例和边缘分布 |
| 真正器件空穴样本 | 建立缺件时的结构与区域特征，不能用送料圆孔代替 |
| 定位孔、白背景、带边、错位等反例 | 用于检验误报，必要时加入排除特征 |
| 成像/尺度与容许偏移 | 保持模板与现场倍率、方向及ROI一致 |

教导阶段允许多张正常样本，挑选稳定的外形特征；不把随机反光、手机拍屏纹理或易变的内部细节硬编码进模型。模型冻结后，使用没有参与教导的独立样本验收。

配方可先保存几何参数、区域特征范围和小模板/掩码；暂不需要数据库、模型服务器或大量型号。未来换型更换配方和模型，底层处理框架保持通用。

## 3528第一版建议

### 识别层

使用固定机位/倍率和有限允许偏移，限定在载带候选区域处理。先建立真正穴位的坐标参考，再检查该位置的3528特征。

有件证据采用两组空间特征：

- 灰度分割后白色主体的面积、宽高、位置和近似矩形外形；不能只用整个80×80的平均亮度。
- 稳定外轮廓的方向/位置分布或低分辨率边缘模板；不能只加总EC/GS。

针对圆形送料孔，至少要求它不能仅凭亮度、黑色背景和大量轮廓被接受为3528。长宽比或单一圆度也不能单独保证拒绝所有混淆，应通过正反样本检验特征组合。

第一阶段不承诺全图任意旋转/缩放、任意型号识别。若后续允许载带倾斜移动，必须明确位置校正与模型允许变化范围，不把超出范围的图像硬判有件或空穴。

### 结果层

| 前置状态及识别证据 | 正式结果 |
|---|---|
| 图像/核心不完整或新参数尚未生效 | 待采样 |
| 载带/真正穴位没有建立可信位置 | 无有效目标/位置异常 |
| 穴位有效，3528模型匹配且区域特征成立 | 有件 |
| 穴位有效，真实空穴特征成立且无有件证据 | 空穴 |
| 两类证据都不足、相互冲突或成像质量不足 | 不确定 |

**没有匹配到有件，不等于空穴。** 送料孔所在位置不应进入器件穴位分类。图像采样有效、目标有效、模型匹配分别显示；MEAN/EC/GS只作为解释和调试数据。匹配得分不直接命名为识别概率或准确率。

### FPGA落地路径

先用相机原始帧离线比较两种候选：几何/区域特征组合，或在其基础上加入小型边缘模板。离线正反样本能分离后，再选择更小的方案落RTL。没有必要照搬完整PatMax/HALCON。

轻量模板可研究16×16或32×32二值轮廓并配掩码、有限位置搜索。这是预算候选，不是已确定实现。32×32轮廓+同尺寸1bit掩码的纯存储量为2048bit=256字节/模型；三个模型为768字节，尚未计算变体、元数据、缓存和匹配逻辑。小存储量不能证明系统资源/时序一定足够。

现有V4构建Slice57.63%、ERAM48/108、DSP8/40，可用作增量比较基线；新算法必须另做冻结仿真、综合、ERAM映射和布局布线。还应保留完整视频与检测结果隔离，不能因模型未匹配再次黑屏。模型/位置/灰度/结果须同帧同参数发布。

## 下一步需要的证据与验收

1. 固定3528成像条件，取得相机原始帧；手机照片用于记录现场误报，不能直接当native像素模板冻结。
2. 人工标记正常3528、真正空穴、送料定位孔、无载带背景、边缘/错位场景；确认真实空穴的物理结构。
3. 教导集与独立验证集分开。已有送料孔误报必须作为拒绝案例；不能只演示正常白件被匹配。
4. 给出有件漏检、空穴误检、定位孔误报、无目标误报和不确定结果的记录。模型门限仍要验证，但先证明空间特征具有区分能力。
5. 只将通过离线验证且预算可行的最小识别方案集成；黑色/透明仍不扩展。

本轮没有训练实际模板、修改RTL/原门限、运行新ModelSim/TD、发布新bit或执行板上操作。V4仍只能作为特征采样实验，不应按可靠对象识别版本验收。
