# FPGA接口与异常处理约定

> 2026-09-07批准的实现约定。空白由实际工程和测试填写；硬件语义未确认前不凭模块名称猜测。

## 1. A版写检测RTL前填写

| 字段 | 必须确认的内容 | 实际约定 |
|---|---|---|
| 数据格式与位宽 | RAW、RGB或灰度；通道次序；检测支路插入点 | 候选u_isp_top/u_awb后96位RGB888，组内R/G/B；见12验证记录 |
| 每拍像素数PPC | 96位RGB含四组24位；以所选接口源码为准 | 4，保持并行 |
| 像素顺序 | 哪组为最左像素；坐标如何递增；同拍跨ROI如何累加 | 按显示字节顺序[95:72]、[71:48]、[47:24]、[23:0]；有效拍x增加4，ROI逐像素掩码已实现，支持非4对齐边界 |
| valid | 哪拍数据有效；无效拍坐标是否保持 | AWB有效块；无效拍坐标应保持，但有效块不保证采集帧完整 |
| sof | 帧开始与第一有效像素同拍还是提前，原user如何映射 | 当前user提前，模型仿真53/55拍；检测专用O_pixel_sof=I_tuser_r2&&O_tvalid已引出，不改DDR早帧通知 |
| eol | 行末与最后有效像素对应方式；核实原last实际含义 | AWB last与有效块最后一拍同拍；非采集完整证明 |
| 帧结束 | 如何确认最后一行，不能仅凭信号名判断 | AWB无独立FE；需输入完整性上下文，64拍残缺行仍回放256拍，RAW采集与AWB处理双侧完整性保护已实现，见14说明 |
| ready及回压 | 上游能否停；不能回压时的FIFO和溢出策略 | ready仅透传，不能停像素流水；不得拉低ready暂停相机 |
| 时钟与复位 | 源/目的时钟、复位释放顺序、跨域方法 | 检测源S_csi_rx_clk、S_rst_n低有效；配置与统计分别通过稳定邮箱跨域，SDC约束物理延迟 |
| ROI | 固定范围、生成时刻、完整有效条件、边界处理 | 观测[256,768)×[172,428)，统计[472,552)×[260,340)共6400像素；SOF清零，只有完整有效候选帧提交，青框归属见18 |
| 特征及判定 | 累加清零/结束、位宽、延迟、有效与等待状态 | gray=floor((R+2G+B)/4)，sum28/count20；两级归约流水＋帧后28拍除法；MEAN/MIN/MAX/sample_new原子更新；均值判定UNCAL/WAIT/PRESENT/EMPTY，原生FS清旧判定/取消旧计算，最近完整统计保留；默认未标定，见16 |
| 结果帧号 | 采集frame_id如何随特征与结果传递 | 单候选上下文，无结果frame_id；新增单帧均值判定，native FS重置新鲜度，不绑定DDR帧 |
| 显示帧号 | DDR写入/读出和结果快照如何对应 | 尚未帧绑定；显示最近有效采集统计，固定观测框，不声称对应当前DDR显示帧 |

A版可用固定检测区和静止样品稳定后判定；无需先构造全功能动态框架。任何已启用的框/结果必须与显示内容语义一致，样品改变后不得继续把过期结果标为当前。若实现运动框，帧匹配须在该版本通过。

2026-10-03 ModelSim复核：上表像素路径的53/55拍等数值，在原厂ERAM模型且测试台强制未连接RAM输入为0的诊断模式下得到复现；原工程未连接`web`时像素首拍失败，不能称原厂模型原工程验证通过。下一批次先确认显式接零这一前置修复并重测，见12文档及ModelSim验收记录。

随后用户已确认并完成只读端口接零：默认ModelSim八项通过，未启用测试覆盖。既有延迟帧标志探针通过；后续14批次已用真实ISP验证全600行、短行/长暂停与恢复，ROI单元验证抢占/重复SOF等。物理MIPI/DDR/HDMI端到端仍需现场验证。历史失败记录保留，不把修复前后版本混为同一验证结果。

每个新模块检查多像素排列、行/帧边界、valid间断、复位首帧和输出延迟。串行化四像素需验证突发吞吐、时钟与FIFO，不以平均帧率代替带宽证明。

## 2. B版增加的时间与位置接口

| 字段 | 约定 |
|---|---|
| run_id与pocket_id | 本次运行段标识+相对穴位编号；重同步换运行段 |
| sync_state | 未同步、跟踪中、可信暂停、失锁、重同步 |
| sample_time与position | 采样时间或位置基准，说明读出/处理延迟 |
| P0/P1与phase | 孔节距、穴位节距和起始相位、方向 |
| ROI生成方案 | 扫描先行+必要缓存 / 上帧预测 / ROI缓存；填写误差边界 |
| display_snapshot | 采集帧和DDR显示帧配对；原子更新，不能拼接不同帧字段 |
| event_valid | 只锁定一次正式判定；禁止把重复显示帧当新事件 |

## 3. 相对编号状态机

正常连续运行可以保持第1、第2、…第127穴的相对编号；不承诺整卷永久绝对号。受控暂停且历史可信可以保留编号。丢帧/滑移/手动移动使位置超出可信范围时失锁并暂停送料。

| 参数 | 需要测试后填写 |
|---|---|
| 最大容许观测间隔及对应位移 | |
| 视觉与步进预测最大偏差 | |
| 孔尺寸、间距和相位有效范围 | |
| 重同步需观察的有效孔/穴条件 | |
| 旧运行段未决NG确认及隔离动作 | |

禁止失锁后继续用旧号停车；禁止静默清队列并放行。重同步由操作者确认受影响带段、旧NG状态及新起点，再建立新run_id。

## 4. C版NG队列与控制接口

事件至少包含run_id、pocket_id、defect_mask、sample_time/position、判定有效性和处置状态。按事件键去重，按物理顺序逐个处置；暂不自动合并相邻NG。

| 条件 | 必须行为 |
|---|---|
| 单个或连续NG | 保留每个未决事件，停到队首对应实物穴位 |
| 复检失败 | 保持当前事件和停车，不重复入队 |
| 复检通过 | 当前事件完成，确认编号可信后继续下一事件 |
| 人工隔离 | 明确受影响带段、事件和原因，记录后才结束相关事件 |
| 达高水位 | 提前受控停车，预留停止过程中产生事件的容量 |
| 满队列/写入溢出 | 故障停止并标记记录可能不完整、受影响范围需人工核对；不静默丢弃继续送料 |
| 失锁 | 冻结队列和结果，禁止按旧位置停靠；走重同步确认流程 |

容量按最坏连续NG和判定在途量确定。可用容量至少覆盖高水位触发后停止期间可能产生的NG、尚未提交的判定和余量；使用实际运行速度、最小穴位节距和最坏停止时间计算，并以全NG带验证。

| 待填控制参数 | 实际约定 |
|---|---|
| STEP/DIR/EN极性、电平和脉宽 | |
| 脉冲/mm、最大速度与位移校核 | |
| 最坏判定及控制时间 | |
| 最坏停止时间与停止距离 | |
| 检测到处置距离与误差余量 | |
| FIFO深度、高水位及停车储备 | |
| 处置窗口、复检按钮和继续条件 | |

## 5. 联调必测场景

A：多像素与帧行边界、复位、样品更换、Logo、处理视图和冷启动。

B：电机关闭/匀速/启停、灯光开关、视频中断、孔遮挡、滑移、手动拖动、可信暂停、失锁恢复；动态框实施时检查帧配对。

C：单NG、相邻NG、间隔NG、全NG、高水位、满队列、复检失败、停车中失锁、旧运行段NG未处置时重同步。


## 6. 2026-10-05取样界面接入

用户明确采用取样界面。本版保留原classifier采集帧新鲜性，另用roi_result_snapshot发布最近完整显示记录。正常native FS仍撤销classifier当前帧判定，但不清上一完整显示记录；新sample_new后再等一采集时钟，让新类别与新MEAN/MIN/MAX同一快照发布。坏帧、lane/config和sample_valid撤销记录，FS抢占取消待发布旧帧。

ROI邮箱从27位改为28位：bit27完成翻转；bits26:25状态（0未标定/1等待/2有件/3空穴）；bit24统计有效；bits23:16均值、15:8最小、7:0最大。bit27只在新完整记录发布时翻转，邮箱轮询不翻转。数据不是DDR显示帧绑定，“最近采样”不声称当前帧质量。

显示域roi_display_state检查CFG、独立监测域FPS和实际EXP/GAIN。曝光/增益变化、CFG0、FPS0或无效记录撤销旧有效性；参数/输入恢复有32像素时钟稳定等待，期间记录旧token以排空旧跨域内容，之后必须新完整token才恢复。标定匹配恢复还需新分类token，不允许从保留的统计重建旧类别。累计L/F/I/G只作历史提示，不永久锁故障。

跨域预算不改。CSI周期8.888ns、相机配置时钟41.667ns、HDMI像素19.230ns；考虑已有旧请求在途，每个邮箱新输入到目的更新保守按6目的周期＋3源周期计算（旧请求/ack排空，再发布新内容）。相机→CSI配置撤销→ROI显示按(6×8.888+3×41.667)+(6×19.230+3×8.888)+2×8.888约338.2ns估计，32像素周期615.36ns留有余量；最后两采集周期包含接收端参数比较和撤销寄存器响应。这是持续有钟条件下的物理/同步上界；CSI停钟时由独立FPS撤销，恢复不能凭冻结内容重启。真实相邻采样约37ms，明显长于完整邮箱往返；1bit完成标记不作为任意高速事件队列。

OSD统一3像素时钟：坐标/地址与RGB第1级，同步ROM及元数据第2级，叠加第3级；DE/HS/VS/ENABLE旁路一致。动态字段在VS边界锁存，BCD需16拍，依赖原HDMI垂直消隐；显示撤销最多再等一显示帧边界。上下条[0,80)、[504,600)，不改变原视频坐标或ROI。字模/Logo使用同步ROM，最终ERAM映射须以TD报告确认。

当前CLASS_CALIBRATED=0、T=0占位不改。人工状态注入/阈值仅用于仿真，不代表实物分类或准确率。输入停止检测沿用1秒FPS窗口，约1～2秒；HDMI停钟/显示器断线仍需现场观察。本轮最终仿真与布局布线状态见21实施说明及独立验收记录。

## 7. 2026-10-05独立SW观测实验接入

用户已确认SW1上拨灰度、SW2上拨边缘，四种组合全部保留。两个3.3V输入仅进50MHz两级同步及整个二位状态20ms稳定处理；每次稳定改变递增16位epoch。18位{epoch,edge,gray}分别用稳定邮箱传CSI和HDMI。CSI在原生FS应用，本帧RGB视图不因帧中拨动改变；变化立即取消该帧观察结果，下一完整帧才能恢复。

新增四个256×96位同步RGB行缓存（无数组复位/清零），用下一完整行计算上一行的中心Sobel，再连续输出该行256个PPC4组。读地址/同步RAM、灰度、水平组前看、方向权和、绝对值和、颜色叠加逐级配套valid/x/y/mode；读请求到RGB有效延迟5个CSI时钟，已包含水平组前看的1拍，末组可独立冲刷。尾行完整回放，不引入组内气泡；原96→128打包每4组出3字保持。early通知遇前帧在途回放延后至其排空，与首个打包输出留出FIFO复位时间。原AWB统计支路保留，MEAN不受处理颜色影响。

边缘梯度G=abs(Gx)+abs(Gy)，11位；观测阈值80仅控制橙色叠加和计数。观测框[256,768)×[172,428)边界只显示完整3×3邻域，框外原彩色。核心[472,552)×[260,340)阈上数量13位、全部梯度和24位，梯度有效像素数必须6400。像素计算不新增DSP、开方或变量除法。

83位观察记录原子发布：[82:59]梯度和、[58:46]边缘数、[45:28]本帧epoch/mode、[27:0]原28位完成token/状态/有效性/MEAN/MIN/MAX。只在原完整帧记录完成且梯度核心完整后发布；取消时有效位置0，不能拼旧边缘与新灰度。显示端独立请求变化与EXP/GAIN一样启动32拍排空，tag匹配只屏蔽有效位，不把新记录到达当新的稳定等待起点。停CSI快速往返和epoch回绕仍需新完成token。

MODE在HDMI VS快照当前请求，不保证DDR已读到该模式的帧；采样数据继续称最近采样，不与当前显示帧绑定。边缘关闭或样本无效时EC/GS显示横线，开启有效时显示十六进制数量和梯度和，T80十进制。新增两个请求邮箱的6项物理预算、两个SW异步首级路径及83位原ROI邮箱均需TD核对实际匹配/未忽略。最终报告及镜像见24实施说明，正式分类和硬件性能尚未验收。
