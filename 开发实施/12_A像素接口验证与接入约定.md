## 已核实的像素顺序

检测候选位置：`design_top_wrapper/u_isp_top/u_awb`之后、`u_data_96bit_to_128bit`之前，时钟`S_csi_rx_clk`，复位`S_rst_n`低有效。这个位置的96位是4个RGB888像素，每组高到低为R、G、B。

| 相对显示x | AWB后96位范围 | R/G/B范围 |
|---|---|---|
| x+0 | [95:72] | [95:88] / [87:80] / [79:72] |
| x+1 | [71:48] | [71:64] / [63:56] / [55:48] |
| x+2 | [47:24] | [47:40] / [39:32] / [31:24] |
| x+3 | [23:0] | [23:16] / [15:8] / [7:0] |

测试对真实双线性模块输入线性横向梯度，确认其128位输出低32位为最前像素、相邻组x递增；用R=100/G=50/B=20的BGGR样本确认各通道。data128_96反转四个32位组并丢弃填充字节，AWB保留96位组位置；实际96→128打包输出字节与按显示顺序串接的12像素完全一致。video_out源码按128位高位先取RGB888，作为显示顺序依据；本轮没有仿真DDR、video_out FIFO或从相机至屏幕的全部链路。物理方向与候选ROI位置仍待现场标记核对。

## 帧行控制的实际含义

| 字段 | 验证/源码结论 | 后续检测接入要求 |
|---|---|---|
| valid | AWB输出有效块；正常1024宽一行256拍，每拍4像素 | 仅有效拍递增x；数据与控制同步流水 |
| user | 当前O_tuser直接等于I_tuser，是早于像素的帧通知 | 不能直接当第一有效像素同拍SOF |
| last | `(valid_d1==0)&&(valid_d2==1)`；与最后一拍有效输出同拍 | 只反映输出有效块结束，不能证明输入行完整 |
| 输入last | AWB没有用它确认读出的行长 | 不依赖其名字推断标准AXI行为 |
| 帧结束 | AWB输出没有独立FE；行缓存按固定宽回放 | 完整性检查必须覆盖输入尺寸/行数和中断，不仅数输出valid |
| ready | I_tready直连O_tready，但读写和数据流水不受ready控制 | 检测不拉低ready暂停相机，不用valid&&ready当采样条件 |
| reset | 流水/地址复位，ERAM不清空；正常重启需等待新帧 | 不把复位后旧RAM内容认成新样本 |

连续输入一行256拍、3行测试：768拍输入和768拍AWB输出，576个128位打包字，3个正确最后有效拍。第一拍像素较透传user晚53个时钟。每行第10/180拍前插入2个无效拍时，数据仍完整、输出重新连续，第一拍延迟55个时钟。此测试不证明任意程度的间断都安全；读缓存开始后按固定宽连续回放，长停顿可能读到旧数据。

ready低时仍有180个有效输出拍。输入仅64拍残缺行时仍输出256拍，且没有X（RAM里仍有之前帧的值），证明“数据非X、valid连续、宽度看似正确”都不能代替采集完整性检查。

96→128打包器的I_rst_n未用于内部状态控制，frame_start只打一拍透传；连续valid时拉低reset或发SOF都不重启打包相位。valid=0才清相位，4个96位连续拍输出3个128位字。仅2拍输入后停valid，已发1个128位字，剩余64位丢弃。本轮如实保留这一现状，新增处理不能在行中随意插valid空拍；未来若改此模块，需另做视频集成验证。

## 接入方案（原提案，已按14范围实施）

1. 保留显示/DDR当前使用的早帧通知，不将AWB的O_tuser直接改成延迟SOF，以免改变FIFO清零时机。
   前置修复已确认并完成：`signal_delay.v` RAM只读B口的`web`及`dib`显式接0，默认原厂模型复测八项通过；视频仍由用户上板复核。
2. 为检测提供与AWB像素对齐的专用SOF/EOL、坐标与帧有效上下文。优先验证现有未接出的延迟帧标志是否能提供它；覆盖上一帧尾部未排空时新SOF、截断帧及复位，不能仅凭固定延迟53拍对user移位，因为缓存延迟受输入间断影响。
3. 四像素保持并行，当前拍x0/x0+1/x0+2/x0+3；ROI左右边界非4对齐时逐像素选取，最后一拍累加参与结果。不会用ready降低吞吐。
4. 检测结果必须有本帧有效标志。输入缺行/缺列、帧中断或重新配置时作废，不把旧RAM回放判为空穴，也不沿用旧结果。现有累计FORMAT计数可用于诊断，但不能直接当本帧的有效标志。
5. 灰度/二值处理与旁路保持相同数据/valid延迟及连续性，供显示的现有打包器不因插入检测支路产生任意间断。

用户批准的临时ROI为[256,768)×[172,428)，已采用半开区间并行掩码。正式单穴ROI、判别阈值、样本量/错误目标、换样期间作废方式、结果与DDR显示帧关联仍未冻结。不先新增运动编号、FIFO或串口等无关功能。当前已按14范围接入帧上下文保护与临时ROI统计；下一分类批次须依据正式ROI及有效实物样本确认范围。
