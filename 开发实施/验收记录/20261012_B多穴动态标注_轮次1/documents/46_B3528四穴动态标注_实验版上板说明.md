## 现场先看什么

1. 下载本实验版并复位，顶部应出现 **`AUTO4 EXP V1`**，原 `D3 P… W…` 发布诊断保留。默认曝光2244半行、增益48、R100/B100，白平衡数值仍以64为单位。曝光、增益和手动白平衡按键保留；先在固定光源和机位下测试。
2. 将载带大致横向放置，定位孔排在画面的下方，落入本版的内部孔搜索带。**不用把某一个孔专门对到X464**。需要至少两个合格相邻孔，有足够暗色边界；初始获取后还要再采一帧并复核位置，才可出现有效框。
3. 先停稳，确认框落在真正的器件穴位，不是圆形定位孔或载带边缘。青绿框/“有件”表示PRESENT，橙色框/“空穴”表示EMPTY，黄色框/“待检测”表示定位和取样有效但灰度、边缘结果尚不能一致判定。未标定状态显示黄色“未标定”。
4. 缓慢向左、向右移动并暂停，观察多个框随穴位位置更新。突然快移、遮孔、出界或帧异常会撤销相应框，稳定后重新获取；不把失锁显示成空穴。框和分类属于对应DDR视频帧，更新速度由相机输入帧率决定，不能按HDMI刷新率计算。
5. 把真正空穴放入视野，与有件穴混排验证。定位依靠圆形孔列，不依赖白色器件，所以全空穴载带仍应能够定位；分类是否正确必须由实物真值确认。

## 本版的实验几何

以下均为原生1024×600图像坐标，不是手机照片上的位置。

| 参数 | 当前实验值 |
|---|---|
| 孔搜索X范围 | [128,896)，须留出完整亮孔及两侧灰边/暗边 |
| 孔搜索Y范围 | 340～443，每8行采样，连续三采样行验证 |
| 可见定位孔条件 | 至少两个相邻孔；亮灰度≥120、暗灰度≤100；亮区宽20～64像素；每侧灰过渡最多8像素 |
| 孔距条件 | 96±24像素 |
| 孔中心到器件穴中心 | X加48、Y减80像素 |
| 每穴统计/显示框 | 80×80；左右各16×80参考条带，暗像素至少75% |
| 每帧复核误差 | X≤4、Y≤8像素；超限不继续输出预测类别 |
| 结果上限 | 按横坐标排序的前四个合格完整候选 |

孔距、孔到穴的偏移和倍率**没有经过现场测量**，仅沿用当前3528试用关系。孔距与穴位节距1:1不是其他型号的普适关系。若框整体偏移、尺寸不合适或孔距不符，应先修正这组几何，不宜先改分类阈值。

搜索带是内部算力范围，画面上不再画原来的固定大绿框、三条扫描点阵和X464参考线。仍不是全画面任意方向、任意倍率的目标检测。斜放、大幅纵向移动或反转载带方向超出本次实验范围；同一场景存在多个相似孔列时也未提供身份消歧。

采用上一帧孔位冻结本帧取样区域，再用本帧孔位复核，所以有一帧位置滞后和允许误差。最大可信手动速度未实测；先慢移，观察是否频繁出现MOVE TOO FAST。进入、退出搜索带时，各槽表示本帧横向顺序，不是同一实物永久身份。

## 四种视图与分类

每穴独立累积灰度、最小/最大值、Sobel边缘数量和梯度和，共享一条Sobel及其行缓存。

| 视图 | 实验判定规则 |
|---|---|
| RAW/GRAY | MEAN≥58为有件，否则空穴 |
| EDGE | EC≥96且GS≥32768为有件；EC≤48且GS≤16384为空穴；中间区待检测 |
| GRAY+EDGE | 灰度与边缘一致才给有件/空穴，否则待检测 |

这组门限仍是临时试用值，**没有证明现场分类准确率**。调曝光、增益或白平衡后，画面/阈值关系会改变；本版会撤销参数切换中间帧和旧显示结果，但不会自动重新标定门限。正式测阈值前仍应冻结光学、曝光、增益、白平衡和安装几何。

底部大字和MEAN/MIN/MAX/EC/GS为**第一个横向槽**的统计，其余槽以各自框上的文字为准。第一个槽失效不能阻止其他有效槽继续标注。

## 不出框时看什么

- `NO HOLE`：没有通过孔列验证。检查孔排是否在搜索带、亮暗、宽度、孔距及完整暗边；搜索带边缘缺少暗边的孔不作为完整候选。
- `ACQUIRING/SCAN WAIT`：获取或等待下一帧取样阶段，先停稳。
- `MOVE TOO FAST`：上一帧取样位置与本帧孔位误差超限，先慢移或暂停。
- `ROI INCOMPLETE/CHECK CORE ROI`：检查孔到穴偏移、80×80框和两侧暗带，或灰度/边缘一致性。
- `FRAME STALE/VIDEO WAIT/CONFIG WAIT/PARAM CHANGED`：先检查输入帧、视频写入和参数生效，不把这类异常当空穴。

建议反馈一段静止→慢左→停→慢右的视频，以及同一条件下有件/真正空穴的配对画面。最先确认的是**框是否落在正确穴位、能否随慢移跟随**，再确认类别与真值；二者分开记录。
