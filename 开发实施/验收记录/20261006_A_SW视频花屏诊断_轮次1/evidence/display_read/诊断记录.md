# 2026-10-06 显示 FIFO 下溢与右移机制专项

## 结论与边界

实际 `video_out.v` 和实际 `w128_d512_fifo` RTL 仿真确认：如果一条显示行的开头发生 24 次空 FIFO 读请求，恰对应 128 像素，则随后摄像头像素会相对固定显示坐标右移 128 像素。下一行的左侧 128 像素会显示前一行末尾的 128 像素；位于源 ROI 内 x=700 的橙色像素会显示到 x=828，超出固定 ROI [256,768)。

此测试人为制造显示 FIFO 的数据返回空窗，证明表现机制，**未证明真实板卡发生了下溢，未证明此次 SW 版本中的写 FIFO 丢字直接触发该下溢**。OSD 模块没有在本 TB 中实例化；固定框坐标不跟随摄像头像素移动的结论来自它在显示端独立叠加的架构。现场表现与此机制相容，不能据此唯一确定根因。

## 最小测试

- 实际工程模块：video_out.v、w128_d512_fifo.v、soft_fifo_al_4057d6b76aa6.v，均未修改。
- DDR 时钟 15 ns 周期；显示时钟 19.230 ns 周期，约 52 MHz。
- 两路 DUT 同时输出连续 1024 像素的两行，中间正常水平空白；每行 192 个 128 位词，按源 RGB 字节顺序独立组包。
- 基线在第一行开始前预填 192 词。
- 故障路在显示 x=123 时开始返回第一行数据，经真实 FIFO CDC 后首次有效读取在 x=128。其后返回速率足够，不再制造缺数。
- 两路在第二行开始前都返回完整第二行数据；故障路仍留有第一行末尾 24 词。
- DDR 命令发出接口在测试中被关闭，返回数据由 TB 直接提供。这是显示读取专项，不是 DDR 控制器或完整读写仲裁验收。

## 结果

ModelSim SE-64 2019.2，`run.ps1` 通过，日志 `video_out_underflow.log`：

```text
FIRST_SUCCESSFUL_STARVED_READ display_x=128
ROW0 baseline_marker=700 starved_marker=828 remaining=24
SUMMARY baseline_errors=0 shifted_errors=0 prefix_errors=0
 baseline_underflows=0 starved_underflows=24
 baseline_reads=384 starved_reads=360
 row1_baseline_marker_x=700 row1_starved_marker_x=828 remaining=24
PASS: actual video_out and FIFO reproduce a 128-pixel right shift across two lines
```

基线全部 2048 像素正确。故障路首 128 像素为复位后的零值，随后 1920 像素全部等于原始连续输入序列的 x−128 位置，包含跨行边界。第二行左条与前行尾部的逐像素对应已检验。两行后仍滞留 24 词，水平空白重置显示解包相位并未恢复数据序列位置。

编译 0 错误、0 警告；仿真 4 条既有 FIFO 端口宽度警告（ceb / addrb 的表达式为 32 位，端口分别为 1 / 9 位）。首个直接调用因未继承用户许可证环境失败；脚本继承已有 MGLS_LICENSE_FILE / LM_LICENSE_FILE 后成功，不输出许可证值。先前单行通过日志保留为 `single_line_firstpass.log`。

## 对应代码

- `video_out.v:151` 未连接 FIFO `valid`；152 连接 `empty_flag`，但后续不使用。
- `video_out.v:156–188` 解包相位由显示读使能推进，像素输出不检查 FIFO 的实际有效性。
- `soft_fifo_al_4057d6b76aa6.v:100–121` FIFO 在 empty 时抑制物理读及读地址递增；230 同时抑制 RAM 读取，dout 保持之前的值。
- 因而显示相位继续走，摄像头 FIFO 地址停住；恢复供数后摄像头序列落后于显示位置。未对齐 16 像素组的缺数还可能破坏跨词像素，当前不做进一步扫描。

## 后续建议

在用户确认修复批次后，应先消除新视频回放节奏引入的供数压力，并补 FIFO full / empty 的帧内计数或粘滞诊断与可恢复失效处理。不能只把读取使能与 empty 相与便称修复：现有 FIFO 已这样做，显示坐标无法暂停，缺数后的源序列与显示序列仍然错位。需明确帧边界恢复、预填条件及异常帧处理，再用完整相机→写 FIFO→DDR→读 FIFO→显示回归验证。

当前未改工程 RTL、未生成 bit、未写 AGENTS、未操作板卡。专项开始和结束时均未发现 vsim / vlog / td_commands_prompt 助手后台进程。
