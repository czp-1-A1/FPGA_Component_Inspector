# 用独立电脑信源测试相同1080p30时序（待执行）

这一步用于区分FPGA发送端问题与当前HDMI链路对该格式的接受情况。F照片证明内部事件计数符合目标，仍不能证明外部串行信号正确。电脑测试结果也不能代替FPGA验收；保持原采集/HDMI30 fps目标。

1. 用电脑连接AOC Q24G51F，保持测试FPGA时的同一HDMI线和显示器HDMI口。
2. 打开NVIDIA控制面板 → 显示 → 更改分辨率，选择外接Q24G51F → 自定义 → 创建自定义分辨率。
3. 输入1920×1080、30 Hz、逐行；展开“时序”，标准选择“手动”。填下表：

| 字段 | 水平 | 垂直 |
|---|---:|---:|
| 有效像素/行 | 1920 | 1080 |
| 前沿/前肩 | 88 | 4 |
| 同步宽度 | 44 | 5 |
| 总像素/行 | 2200 | 1125 |
| 极性 | 正（+） | 正（+） |

后沿由总数减出：水平148、垂直36；对应像素时钟74.25 MHz、行频33.75 kHz、场/帧频30 Hz。若界面显示像素时钟，核对为74.25 MHz。以上数字来自本工程目标，NVIDIA文档只用于确认操作入口与字段意义。

4. 点击“测试”。记录正常显示、输入不支持、驱动拒绝或按钮不可用。测试不通过就等待恢复原模式，不保存失败配置。
5. 测试通过后保存并选择该模式，在Windows“高级显示”选择Q24G51F，核对**活动信号模式**为1920×1080、30 Hz，并记录照片。桌面1920×1080、活动信号2560×1440、60 Hz不计本项通过。
6. 测试后可恢复原60 Hz模式，再接回FPGA；无需改动板上Flash。

结果按下列条件解释：

- 电脑同参数正常、活动信号确认：增加FPGA发送端排查优先级，继续检查串行化、物理约束和信号完整性；并非FPGA通过。
- 电脑实际发出同参数但屏拒绝：证明当前屏/口/线/信源组合拒绝该输入，仍需区分具体原因。
- 驱动拒绝或按钮不可用：本项未测，不能据此断定屏不支持。

操作入口：[NVIDIA官方创建自定义分辨率说明](https://www.nvidia.com/content/Control-Panel-Help/vLatest/en-us/mergedProjects/Display/To_create_custom_timings_for_your_HDTV_display.htm)。字段意义：[NVIDIA官方自定义时序对话框](https://www.nvidia.com/content/Control-Panel-Help/vLatest/en-us/mergedProjects/Display/Custom_Timings_dialog_box.htm)。本说明核对日期2026-10-11，具体按钮受本机驱动/连接方式影响。
