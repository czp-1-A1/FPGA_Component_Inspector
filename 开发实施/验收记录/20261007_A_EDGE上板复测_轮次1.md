开始实物测试前约定：

1. 每次切换先稳定2秒，再轻轻移动载带观察10秒，以移动画面是否显示判断更新。
2. RAW、GRAY、EDGE、GRAY+EDGE均应持续显示移动画面；返回RAW应能恢复。
3. 稳定2秒后OF/VF/UF不应持续增长；进入时和观察10秒后分别记录，保留原值。
4. 镜像身份必须由ANLOGIC标志下新增的`ER x LP xxxx WS xxxx`确认。ER/LP/WS为十六进制。
5. FR/SEC变化不能单独证明显示画面更新，ER0也不能单独证明完整帧发布。
6. 卡住时先拍全屏，使ER/LP/WS与FR/SEC/OF/VF/UF清晰可见，再返回RAW记录是否恢复；保留失败，不事后降低条件。

本轮10秒模式复测是诊断检查，不替代八步路线要求的连续30分钟稳定性、冷启动或A版完整验收。
