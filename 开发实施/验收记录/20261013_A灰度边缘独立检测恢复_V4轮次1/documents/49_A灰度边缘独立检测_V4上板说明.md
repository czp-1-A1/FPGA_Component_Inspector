# 3528 固定框灰度／边缘独立检测 V4

这版按用户要求恢复直接特征实验：先沿用旧阈值，分别验证灰度与边缘效果，融合后续再规划。**无需定位孔搜索成功**，也不要求左右暗参考条通过。固定青框由操作者对准真正的器件穴位。

## 镜像与画面

发布镜像：`fpga/component_inspector/release/direct_detection_v4_20261013/camera_to_dsi_display.bit`。以该目录的 `SHA256.txt`、`audit.json` 和当前构建记录为准；旧 V3 镜像保留，不混用。

顶部标记 **FIXED EXP V4 / D5**，默认曝光2244半行、增益48、白平衡R100/B100。相机、按键、RAW/GRAY/EDGE显示方式、DDR/HDMI和完整视频保护沿用当前代码。

检测青框在原生1024×600画面的 `[472,552)×[260,340)`，80×80。绿色大框是灰度／Sobel显示处理范围；分类仅统计青框内6400像素，边缘框线和显示文字不参与统计。

青框上方两行显示 **GRAY 有件/空穴/待检测**、**EDGE 有件/空穴/待检测**。关闭边缘时显示 **EDGE OFF**；原底部“最近采样”和MEAN/MIN/MAX继续保留。

## 当前判定标准

| 开关模式 | 底部主要判定 | 框上独立结果 |
|---|---|---|
| RAW（SW1/SW2均关闭） | 灰度 | GRAY结果、EDGE OFF |
| GRAY（仅SW1开启） | 灰度 | GRAY结果、EDGE OFF |
| EDGE（仅SW2开启） | 边缘 | GRAY结果、EDGE结果 |
| GRAY+EDGE（两者开启） | 灰度 | GRAY结果、EDGE结果 |

开关高低电平沿用已验证的板上配置，不重新定义按键。

灰度使用白平衡后原始RGB：`gray=floor((R+2G+B)/4)`。80×80帧均值 **MEAN≥58→有件；MEAN<58→空穴**。MIN/MAX只用于观察。

边缘使用3×3 Sobel，`G=abs(Gx)+abs(Gy)`。**EC** 为青框内 `G≥80` 的像素数；**GS** 为青框内全部有效G的累加和。**EC≥96且GS≥32768→有件；EC≤48且GS≤16384→空穴；其他→待检测。** 底部EC/GS沿用十六进制显示；上面的门限为十进制。

GRAY+EDGE本版没有融合：例如MEAN高而边缘少，可以同时显示“GRAY有件、EDGE空穴”，底部仍显示灰度有件。这是比较两种试验结果的界面，不代表自动选择谁正确。

## 上板测试顺序

1. 核对FIXED EXP V4/D5与R100/B100，先停稳载带，把真实有件穴位放入小青框；不要对准送料圆孔。
2. 切GRAY，确认出现MEAN和GRAY判断。随后同一位置放真正空穴，记录两组MEAN/MIN/MAX与实物真值。
3. 切EDGE，分别记录两类的EC/GS和EDGE判断；两开关开启时看两行结果是否冲突。无需反复等待TRACK LOCK。
4. 调曝光、增益或白平衡会暂时撤销旧判定，新的完整样本才能恢复；做有件/空穴比较时保持相同成像参数。
5. 采集停止、坏帧、核心不完整或参数变更中的帧显示待检测，不能据旧数值继续判定。

这是固定框、手工对准的最近采样实验；本版不自动识别整个载带、追踪每个穴位或给出类别置信度。固定位置、倍率和光源后再用实物配对样本收紧门限，之后讨论边缘融合与动态定位重新接入。

## RTL接口与验证要点

- 输入仍为CSI时钟域PPC4 RGB888（96位），组内左到右 `[95:72]、[71:48]、[47:24]、[23:0]`；新逻辑没有串行化视频。
- 灰度统计沿用28位累加、20位计数与两级归约，帧完成后28拍顺序除法；EC13位覆盖0～6400，GS24位覆盖6400×2040。没有新增像素乘法器、变量除法、RAM或DSP。
- 直接模式分类选择为组合逻辑；特征／token／视图tag／WBtag仍原子发布。OSD新增两个2位类别寄存器，在显示VS快照，中文字模沿用现有同步ROM，RGB/DE/HS/VS总延迟仍3像素时钟。
- 统计、模式和WB分别在其原CSI／HDMI邮箱协议中跨域，不直接跨接多位像素。完整帧校验、坏帧撤销与显示端32拍参数稳定等待保留。
- 顶层默认TRACKING/MULTI=0，isp_top启用DIRECT_DETECTION；旧跟踪代码、旧融合默认参数保留供后续单独实验。新直接模式旁路了定位／暗参考条条件，仍保留采样有效条件。
- 当前SDC只删除实际编译掉的两个跟踪metadata邮箱共六条命名约束；其余有效CDC时延预算、时钟/I/O与FIFO约束不变。以后重新开启ENABLE_TRACKING，必须同时恢复冻结V3里的六条约束并重跑完整STA，不能直接改参数烧板。
- 冻结验证包括双向特征冲突、门限边界、四视图、真实RAW10/vendor RAM/Sobel独立参考、核心6400与视频614400像素、短帧／模式／WB撤销恢复，以及完整中文字模和同步延迟。正式发布资源与建立/保持余量写入audit。

现场真值验收尚需人工完成；仿真证明链路和规则实现，不证明旧门限已经适合当前实物。
