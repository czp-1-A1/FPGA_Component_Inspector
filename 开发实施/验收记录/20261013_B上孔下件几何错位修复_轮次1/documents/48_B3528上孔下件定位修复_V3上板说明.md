# 3528 上孔下件定位修复实验 V3

本版用于用户确认的固定方向：**圆形定位孔在上，器件穴位在下**。只支持当前3528横向慢移实验，不自动识别翻转、任意角度或其他型号。

## 为什么之前圈到了定位孔

动态扫描前，人工把器件穴位放进固定80×80青框。算法在这个框里算MEAN与Sobel特征，并未自行辨认“这是定位孔还是器件”。固定框放错地方，同样可能误判。

V2将取样位置改成自动估算，但内部假设孔在下、器件在上：下方Y340～443找亮孔，再把框向上移80像素。最新照片的方向相反，等距亮器件可被当成孔锚点，框移到上方圆孔；孔内亮度也可能越过MEAN门限。已用冻结旧RTL反例复现4个圆孔被标有件，不能继续把这类结果当成正确检测。

## 本版改动

- 上方孔搜索Y[168,336)，X[128,896)，保留亮暗、宽度、孔距和三行一致条件；增加采样弦宽局部峰要求，拒绝恒定宽度亮矩形。
- 孔中心到器件穴中心采用X减32、Y加80；每穴框80×80。偏移是当前方向下的试验估计，精确值仍需原生坐标现场核对。
- Sobel处理Y范围延至464，覆盖下方新ROI。
- 元数据参数tag属于整个采集帧，不再依赖首个穴位的有效统计；首槽无效时不误报参数变化、不隐藏其他有效槽。
- 保留V2视频发布保护及D4 W/M诊断，缺结果时视频继续，坏/短/未写完帧仍拒绝。顶部改为**AUTO4 EXP V3**。

## 分类规则与固定框版的比较

| 项目 | 固定框版 | V3 |
|---|---|---|
| 取样位置 | 人工将真正穴位放进青框 | 由上方定位孔推算下方穴位 |
| RAW/GRAY | MEAN≥58有件，否则空穴 | 同一规则 |
| EDGE | EC≥96且GS≥32768有件；EC≤48且GS≤16384空穴；中间待检测 | 同一规则，每穴独立计算 |
| GRAY+EDGE | 灰度与边缘一致才输出有件/空穴 | 同一规则，每穴独立计算 |
| 有效性 | 完整采样、两侧黑带、参数及新鲜度 | 再增加孔获取、当前位置复核及对应显示帧绑定 |

此处“空穴”指应装器件的穴位没有器件，不能把上方送料定位孔当作空穴样本。原阈值仍未获得正式实物配对标定，不能据仿真宣称现场准确率。

## 上板顺序

镜像目录：`fpga/component_inspector/release/upper_hole_geometry_v3_20261013/`。顶部核对**AUTO4 EXP V3 / D4**，默认曝光2244、增益48、R100/B100，原调参按键保留。

1. 先停稳载带，让上方定位孔排横向经过上半幅搜索带；不要求某一个孔对准固定X线。
2. 先用GRAY看位置：大框应落在**下方器件穴位**，圆形定位孔不应被分类。若框位置仍偏，先反馈完整画面核对几何，不通过改MEAN阈值掩盖错位。
3. 确认位置后，分别用有件、真正空穴和混排检查类别，再切EDGE/GRAY+EDGE。组合模式出现待检测可能是两种特征不一致。
4. 最后缓慢左移、停、右移、停，核对框与对应穴位随动。快移、倾斜、出搜索带或反向安装会失锁，应等待重新获取。

底部MEAN/MIN/MAX和大字仍显示第一个横向槽。首槽无效时底部待检测不代表其余框都无效；其余槽看各自框上的文字。缺结果可看D4的M字段：ready/接收帧号低8位/写入帧号低8位；W1C200是完整115200字，PFB不代表分类准确。
