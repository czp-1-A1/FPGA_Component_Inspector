## 第一轮对准

保持相机、光源固定，3528器件正面朝镜头，定位孔在器件下方，孔列在相机画面内尽量水平。停止按键调参；WB TUNE本身不会禁止检测，但改动EXP/GAIN/R/B/视图会取消参数不一致的帧。

失锁时会显示黄色虚线80×80对准框，先把一个有件穴位中心对准该框中心。三条下方黄色搜索行应同时切过圆孔，参考孔靠近黄色竖线；扫描范围内至少看见一个相邻孔。对准框仅用于摆放，不代表已检测到器件。锁定后该框替换为青色移动检测框。

初始器件中心为相机画面(512,300)，核心X[472,552)、Y[260,340)；孔参考位置为(464,380)，搜索行Y372/380/388。像素坐标不是手机照片的坐标。默认倍率需满足孔横截宽20—64像素、孔距96±24像素、亮孔≥120/暗带≤100，左右各至少8像素暗边。三行孔中心差≤4像素，外侧截宽为中间的至少一半且不大于中间+4像素。几何、亮暗为试用值，未由照片标定。

如果黄色孔标记和器件对准框不能同时对上，请记录实际孔/器件间距与倍率；不要只靠平移把孔对上却让器件离开核心。当前版本尚无按键调ROI/孔高度/阈值菜单，换镜头倍率仍需修改参数并验证。

## 下方孔位的帧对应与运动范围

器件比下方孔先被扫描。程序在帧开始时用上一完整有效采集帧的孔位冻结本帧80×80检测框；稍后本帧三行孔扫描复核位置，误差不超过4像素才允许本帧分类有效。最终提交的统计、检测框坐标、孔复核结果、EXP/GAIN/WB/视图标签随同一完整DDR图像槽发布。没有把新孔位框配到按旧框采样的统计上。

连续两帧有效采集建立锁定。慢向左、慢向右和暂停应有效；空穴也能依靠孔位定位。移动中框相对本帧目标可滞后最多4像素，此范围属于本版本明确容许误差，不是精确到像素的追踪。当前输入26/27fps时，应控制为每个有效采集帧约4像素以内；曝光模糊、实际读取时间及手动加速度会进一步影响可用速度，不承诺毫米/秒。

超过4像素显示MOVE TOO FAST并撤销分类；孔消失、几何不符、越界、参数不匹配或旧图像槽重复约115ms，也显示待检测。失锁后把目标移回初始标记附近，静止重新建立锁定。周期孔突跳整孔距仍可能混淆相邻孔；没有工业穴位身份/编号/电机/NG停车功能。

## HDMI诊断文字

TRACK LOCK表示定位和统计发布条件具备；有件/空穴仍看左下分类。TRACK WAIT会附具体原因，ROW显示本帧三行各自通过候选孔宽、暗边、间距和距离检查的位图（上/中/下行分别bit0/1/2，7表示三行均找到候选）。ROW不是原始亮像素数；即使看见圆孔，灰度、宽度、孔距或初始横坐标不符也可能ROW0。

| 提示 | 意义与下一步 |
|---|---|
| SCAN WAIT | 当前诊断还没有完成三行搜索；先静止等完整采集 |
| NO HOLE | 一条或多条搜索行没有合格候选；检查三行是否切孔、孔亮暗、宽距、相邻孔和黄色横向参考位置 |
| HOLE SHAPE | 三行候选的中心/宽度不一致；检查倾斜、切到孔边或非圆孔光斑 |
| OUT OF RANGE | 核心框已超过有完整侧条/边缘邻域的安全范围；回到初始位置 |
| ACQUIRING | 首个有效采集，等待第二帧复核 |
| MOVE TOO FAST | 当前孔推算中心与本帧实际采样框相差超过4像素；回初始位置、静止重锁，再减速 |
| CAPTURE BAD | 采集上下文取消；坏采集不发布为新的完整图像，显示也可能转为FRAME STALE |
| FRAME STALE | 没有完整显示槽，或同一槽重复超过约115ms；检查相机和完整帧发布，不用累计VF猜原因 |
| CONFIG WAIT | 相机配置未完成 |
| NO INPUT FPS | 独立输入帧率为0 |
| VIDEO WAIT | DDR采集或显示传输尚无有效状态 |
| PARAM CHANGED | 显示帧EXP/GAIN/WB/视图标签与当前设置不匹配；停止改动等待新完整帧 |
| ROI INCOMPLETE | 该完整帧统计或边缘核心像素不齐；记录现场画面排查，不能判空穴 |
| CHECK CORE ROI | 位置与统计具备，但原分类返回等待；检查核心是否落到器件/空穴及暗带侧条条件 |
| OK | 上述显示条件具备，分类仍需独立真值验证 |

多个条件同时不满足时显示一个优先原因，先处理当前提示再观察。所有提示在HDMI帧开始锁存；不会帧中跳字或跳框。帧完整性/参数取消可能阻止坏帧元数据发布，因此不会承诺每个坏输入都能在当前显示图上看到CAPTURE BAD。

## 现场验收顺序

先拍一张包含黄色框、下方孔标记、诊断文字和ROW的静止对准画面，确认LOCK。然后慢左/慢右/暂停；遮孔、快速移位和移出范围应待检测；恢复时先回到基准重锁。固定成像参数后，采同穴有件/空穴的左中右、静止/慢移配对记录。追踪锁定不能代替分类准确率验收。

曝光、增益、R/B和四视图保持原操作，KEY1+KEY2长按约1秒进/退WB TUNE，四键调红蓝-/+；复位EXP2244/GAIN48/R064/B064，无掉电保存。原MEAN/EDGE算法及分类门限未改变；物理分类仍未标定验收。
