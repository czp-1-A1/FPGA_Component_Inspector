# A检测方案SW切换与按键分工：已确认实验范围

日期：2026-10-05。用户先纠正：两种算法叠加是否保留须上板验证，不能提前去掉；SW1上拨开启灰度、SW2上拨开启边缘，独立手动组合比较三类物料。随后回复“可以”，已授权此取样实验版的RTL/约束、ModelSim、TD及独立bit生成；实施与证据见24。正式分类仍需实测反馈后另行确认。

## 1. 用户方向与实现含义

先拟定一个可切换的取样实验版，在同一个bit中观察原图、灰度、边缘和灰度加边缘四种状态，无需反复更换bit。四KEY继续调曝光和增益，用户手动比较效果。

当前SW直接控制灰度和边缘处理的观察状态，不按三类物料编码。黑带黑件、黑带白件、透明载带分别上板比较后，由用户反馈，再拟定各类正式判定代码及参数；不能现在把某种物料固定绑定某算法，也不能现在删除两者同时开启的实验状态。

同时显示灰度底图和边缘，与把两个检测判定按与/或融合，是两个不同事项。实验版先让用户观察单独及同时开启的效果，不预设融合判定规则；最终是否需要组合特征，须有件/空穴实测后再决定。三类物料均未正式标定，CLASS_CALIBRATED保持0，不输出实际有件/空穴结论。

此前复用KEY、两位物料编码或三个SW单选的建议均已被最新指令取代，不再等待这些操作偏好的答复。透明载带器件外观尚不明确，可在实测记录中补充，不阻塞本轮独立开关方案讨论。

| SW1 | A4 | SW0 | 用户输入，拟用于开启/关闭灰度显示 |
| SW2 | B4 | SW1 | 用户输入，拟用于开启/关闭边缘显示与观察 |

## 3. 已确认的独立开关实验方案

| 操作 | 建议行为 |
|---|---|
| KEY1/KEY2 | 保留曝光减/加及现有单键长按连续调节 |
| KEY3/KEY4 | 保留增益减/加及现有单键长按连续调节 |
| SW1 | 上拨开启灰度显示，下拨关闭灰度显示 |
| SW2 | 上拨开启边缘显示与观察，下拨关闭边缘显示与观察 |
| SW3、SW4 | 暂留，不增加其他功能 |

编码顺序明确写成(SW1, SW2)，上拨=1、下拨=0。已确认显示行为如下；RTL向量[1:0]为{SW2,SW1}：

| SW1位置 | SW2位置 | 绿色观测框内的实验视图 |
|---|---|---|
| 下(0) | 下(0) | 原始彩色，不叠加边缘 |
| 上(1) | 下(0) | 灰度底图，不叠加边缘 |
| 下(0) | 上(1) | 彩色底图，橙色叠加边缘 |
| 上(1) | 上(1) | 灰度底图，橙色叠加边缘；保留用于组合效果比较 |

框外维持彩色，绿色512×256观测框和青色80×80统计框保留。Sobel内部仍从原像素的灰度计算；SW1控制显示底图是否变灰，不把它作为Sobel计算的先决开关，因此SW1下拨、SW2上拨也可观察边缘。

保留青框MEAN/MIN/MAX，边缘开启且获得完整有效帧后显示边缘计数EC/梯度和GS；关闭边缘或样本无效显示横线，不能留下旧数值。原灰度统计从叠加前的同一输入计算，不被显示模式或边缘颜色改变。初始Sobel观察阈值80，和正式有件/空穴阈值无关。

不增加组合键或菜单，不自动修改曝光/增益。屏幕显示当前处理状态（原图/灰度/边缘/灰度加边缘）及未标定/等待采样，保留既有字体、Logo和异常处理。分类阈值与边缘观测阈值分开，T58不启用。

## 4. 切换时序和状态

1. SW是保持位置的拨动开关，按稳定电平独立开启功能，不能每个时钟周期循环切换。逐位同步后对两个使能位做约20ms稳定确认；上电稳定后按实际位置选择。逐个拨动产生的中间组合也合法，不猜测最终意图。
2. 检测到新请求后撤销旧观察统计，显示等待采样，丢弃旧状态的在途帧和待发布内容。
3. 检测源时钟域在新的帧起始应用开关状态和参数，整帧使用同一状态；显示域按自身帧边界快照，不能直接接异步SW。
4. 新完整有效帧的特征、开关状态和切换代次原子发布，显示只接受当前已确认状态的新统计。往返切换也不能重新接纳旧邮箱。
5. 坏帧、调参、停流及复位遵循现有撤销/恢复约定；没有新完整样本时不沿用上一方案的判定。当前未绑定DDR显示帧的限制继续保留，静态调试不能宣称已经完成动态帧绑定。

## 5. 资源与验证要求

运行时关闭显示功能不意味着释放已经编译的逻辑资源。共享摄像头、灰度、坐标、帧保护、CDC和显示链路，Sobel行缓存使用ERAM；保留02规范的资源门槛及正确建立/保持时序。当前基线Slice67.12%、ERAM36、DSP8仅是增量对照，新增后的资源和时序必须重新TD验证。

本批验证要求：

- 在相同输入像素/ROI下，四种状态的MEAN/MIN/MAX应一致，并与冻结基线对照；边缘显示不修改统计输入。
- 验证四种开关组合、上电位置、抖动、逐个拨动经过中间状态、快速往返、帧中切换及停CSI时切换；两者同时上拨是合法实验状态。旧统计不能复活或跨状态拼接。
- 保留现有KEY四键操作、配置握手和异常恢复，覆盖KEY调参与SW切换同时发生的情况。
- 继续执行22中的逐像素Sobel、RAM预热、坏帧取消、视频同步和旁路测试；ModelSim后再做TD综合、布局布线、资源/建立/保持时序与约束覆盖报告。
- 三类物料均保持分类未启用；用户分别比较各类有件/空穴的原图、灰度、边缘和同时开启效果，再反馈适用方法及曝光、增益、光源条件。机构未固定时先记录观察与统计差别，不把画面更清楚等同检测准确率已通过。
- 是否保留组合特征、怎样融合判定、各类ROI/阈值及误报/漏检验收，均在实测反馈后另定，不提前删除或默认启用融合判定。
