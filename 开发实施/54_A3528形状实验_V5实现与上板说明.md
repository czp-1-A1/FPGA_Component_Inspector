# 3528形状实验V5实现与上板说明

当前实现是固定青框的形状配方实验。用相机叠加前RGB分割并测量大小、宽高比例、面积占比，再与3528白件/真实小空穴/大送料孔的初始范围比较。MEAN仍作诊断；边缘算法保留橙色叠加，EDGE ON/OFF表示视图功能，不能解释成有件/空穴。

## 本次采用的方法

已吸收“按型号录入特征再比对”：3528W配方的形状范围记录在tools/shape3528/3528w_board_trial.json，并在roi_shape_model.v中落地。它是轴对齐宽高和前景面积的轻量近似，不是完整图像模板库，也不与离线Otsu/旋转外轮廓/角区特征算法等价。没有加入黑色或透明器件配方。

照片推算完整白件约77×61像素，小空穴約20，大送料孔約32。手机图像不适合直接校准相机灰度；新增分割门限100是待实物验证初值，旧MEAN58不再决定主结果。

| 条件 | 初始规则 | 显示 |
|---|---|---|
| 完整白件形状 | 长52–78、短40–72、比1.05–1.55、面积/包围框≥85% | MODEL有件 |
| 真实小圆空穴 | 长10–26、短8–24、比≤1.4、填充60%–90% | MODEL空穴 |
| 大圆送料孔 | 长28–46、短20–42及圆形范围 | NO TARGET（非检测对象） |
| 前景触青框边或两侧黑带参考不成立 | 拒绝目标 | NO TARGET |
| 无前景/尺寸或形状无法匹配 | 保留疑问 | UNCERTAIN（不确定） |
| 帧无效、参数刚改变或统计尚未完成 | 不发布分类 | 待检测 |

两侧参考是青框外各16×80像素，至少75%灰度≤100；仅判断黑带背景，不能独立定位穴位。若相邻白件侵入参考区域也会拒绝，需实物核对。空穴定义只适用于用户确认的3528载带小圆开口；相机倍率、载带、光源或成像设置变化后必须重新验证。

## 操作与观察

使用此版专用bit后核对顶部D6、SHAPE EXP V5，EXP2244、GAIN48、WB R100/B100。保留原按键和四种显示模式。将一个完整白件或真实小空穴对准青框，框内只放该目标，固定位置数帧后看最近采样。此版仍由人工对准固定青框；不支持移动框或自动追踪。

显示FG/W/H/T：FG是原生前景像素数，W/H是像素宽高；FG/W/H按十六进制显示，T100为十进制分割门限。例如FG0E58/W44/H36表示面积3672、宽68、高54。切到RAW仍测同一原始RGB，GRAY/EDGE开关不会改变形状类别。

先依次验证同位置：有件、取出后的真实空穴、上排大送料孔、完全移开载带后的背景。预期分别有件、空穴、NO TARGET、NO TARGET；纯黑或模糊/不匹配可能UNCERTAIN。保存完整屏幕照片和FG/W/H，禁止在没有目标时仍显示有件。若完整白件一直不确定，先看包围框与分割面积，不直接调低门限使其通过。

## RTL接口与资源依据

同CSI像素时钟，PPC4高24位为最左像素；gray10位和四lane掩码经两级归约后累积。13位面积支持6400，7位偏移/宽高支持80，7×7包围框面积14位，比例比较最大128000用18位。SOF清累计，cancel/new FS撤销有效性；完整计数且帧guard提交后，延后两拍提交控制、两拍面积/分类计算。无像素图缓存，结果早于现有28拍均值计算完成，随原结果快照发布。

复用既有115位观测邮箱（位[114:83]WB，[82:46]新37位特征，[45:28]模式tag，[27:0]结果token/状态/有效性/MEAN/MIN/MAX）。37位={2零,FG13,W7,H7,T8}，整组原子更新；CSI到HDMI仍用原稳定邮箱和原SDC物理延迟预算。SHAPE_MODEL旁路恢复V4算法；top默认开启固定单穴形状实验，TRACKING/MULTI路径不启用形状模块。HDMI结果是最近采样，不与DDR画面逐帧绑定。

预计增加比较、计数器及帧后乘法，具体以TD报告为准。TD实测Slice12547/21216=59.14%，ERAM48/108，DSP17/40，相对V4增加321Slice、0ERAM、9DSP；工具将部分常数乘法也映射到DSP。建立+0.151ns、保持+0.020ns、TNS0，STA92.68%；时序余量较小。SDC逐字保持，31条max_delay全部匹配、ignored0；综合125/物理10告警与V4一致。资源足够不等于算法现场准确率已通过。
