载带智检仪 / SYSTEM GUIDE 01

先看懂我们要做什么

A版先把静止载带的正常件与空穴分清，再扩展到运动检测和停车复检。

A · 步骤1—4

视频识别版

官方视频 → 固定检测区 → 单帧存在／空穴判定 → 处理画面、结果文字与安路Logo。
固定机位、静止样品即可。

B · 步骤5—6

连续检测版

短带运动与干扰验证 → 找定位孔 → 相对编号 → 动态检测与失锁恢复。
编号必须对应真实穴位。

C · 步骤7—8

停车闭环版

停止距离实测 → NG事件队列 → 按序停靠 → 人工处理 → 按键复检。
未处理事件必须保留。

你现在可以开始：步骤1不依赖完整机械结构；临时稳定支架可预试调焦与视场。步骤2正式通过仍需固定与重复装夹证据。先实测成像，再定支架尺寸。

整机关系：载带与补光 → 摄像头 → FPGA → HDMI显示；C版由FPGA经驱动器控制送料电机，带动载带形成运动闭环。
版本A/B/C ≠ 团队A/B/C组。以下为设计与开发说明，模块名称是建议职责划分，须映射到实际Lab 1源码；本次未审计RTL实现，也未把计划或官方成绩标成项目已通过。

步骤1做到什么程度算过

先建立一个能随时退回的官方视频基线，这一步不加入检测算法。

摄像头 → MIPI / CSI → 官方ISP → DDR2帧缓存 → HDMI → 显示器
检查需要达到的结果保留的证据
硬件与模式核对实物丝印、摄像头、排线与约束；先用Lab 1的1024×600配置。板卡／相机照片、TD版本、工程与镜像路径
实时与稳定移动物体时画面随之变化；连续30分钟无未解决的黑屏、花屏、冻结、撕裂或重启。起止时间、录像、人工说明；有计数器则保存前后值
输入与输出实测输入分辨率、输入帧率；另记HDMI模式。显示刷新率不能替代相机帧率。输入帧计数／测量方法与日志；未测项明确标注
本机工程综合与布局布线完成；正确约束下建立／保持时序通过，关键路径无未解释的未约束项。本机资源、时序和约束覆盖报告
固化启动按板卡流程固化；断电再上电，无需重新下载或补配关键参数即可运行。冷启动录像，每次成功或失败记录
“看到画面”是初步跑通。没有错误计数器可记录“30分钟内人工未观察到异常”，不能宣称零丢帧。30分钟是本计划检查窗口。

载带智检仪 / SYSTEM GUIDE 04

A版算法：先用最小统计完成正常／空穴判定

先在电脑上用真实样品验证公式与阈值，再由A组翻译成定点RTL；算法方向不能只凭“黑或白”猜。

计算顺序建议RTL职责算法与输出
① 灰度gray_threshold示例整数近似：Y = (77R + 150G + 29B + 128) >> 8。仅适用于确认后的8位RGB；系数是候选方案，要与定点金标准一致。
② 固定ROIfixed_roiinside = x0 ≤ x < x1 且 y0 ≤ y < y1；只统计检测区，不需要先找到定位孔。
③ 定义前景gray_threshold示例：fg = Y < T（暗目标）；也可选亮目标或区间阈值，具体由样本对比决定。
④ 累加特征feature_accum面积 N = Σ(inside ∧ fg)；可选亮度和 S = Σ(inside × Y)。每个有效像素最多计一次，ROI结束时锁存。
⑤ 单帧判定decision_engine比较N或S与预先确定的阈值／区间，输出存在、空穴或等待有效判定。不能默认“面积小就是空穴”。
⑥ 显示结果result_bridge + osd_overlay传递frame_id、result_valid、类别与必要特征；静止并采样完整后才显示有效结果，换样后作废旧结果。
示例位宽推导：ROI含M个像素时，面积位宽为 ⌈log₂(M+1)⌉；8位灰度和位宽为 ⌈log₂(255M+1)⌉。同拍多像素先按各自ROI掩码求和，再更新累加器；不在像素路径做变量除法。

B组交付：原始图、物理真值、调参／独立测试划分、公式、舍入规则、阈值、逐帧期望结果。建议每类至少30个独立样本，最终样本量与误报／漏检目标须测试前约定；同一穴位连拍不算新增独立样本。

载带智检仪 / SYSTEM GUIDE 05

先约定接口，再写检测 RTL

04接口表中的空白需要查实际工程与测量填写。以下是接口契约，不是已经确认的信号定义。

边界要确认什么接错会发生什么
ISP → 检测格式、位宽、PPC、通道／像素顺序、valid、sof、eol、最后一行判定。96位RGB含四组24位只是待核对的接口线索。坐标错位、ROI边界漏算、帧尾丢像素
每拍多个像素各lane的x坐标与ROI掩码；valid间断时何时前进；末拍有效lane；累加清零／结束时序。同一拍横跨ROI时多算或少算
流水与回压data与valid／sof／eol／frame_id同步延迟；上游能否停、FIFO溢出怎么办。图像撕裂或结果对应错误帧
采集 → 显示像素域、DDR用户域、HDMI域的真实时钟关系；多位结果用异步FIFO或稳定握手原子传输。多位字段撕裂，结果与画面不一致
DDR帧 → 结果写帧、读帧、结果快照的关联；A版固定ROI静态有效策略，B版动态框必须通过帧匹配验证。将上一件的结果当成当前件
换样 → 等待建议以明确换样／采样触发作废结果，等待稳定并重新采样；若选自动稳定检测，需另行验证。旧OK继续显示，掩盖尚未完成的检测
多像素串行化必须证明突发吞吐、时钟和FIFO容量足够，不能只看平均帧率。基线可采用PPC并行比较＋加法树，状态字段随流水传递。

载带智检仪 / SYSTEM GUIDE 08

哪些算法现在做，哪些以后再加

OK只代表通过当前已启用的规则。存在判定通过，不等于极性、偏位和角度都已检测。

阶段功能／算法RTL实现与启用条件
A必做固定ROI面积／强度统计比较、累加、帧或ROI结束锁存、区间判定；先通过正常／空穴独立测试。
B新增孔位投影＋相对编号hole_detector / pocket_tracker / roi_generator；实测P0、P1、相位与方向，验证失锁及重建。
C新增队列与运动状态机event_dedup / defect_fifo / motion_controller / recheck_fsm；先实测停止距离与事件容量。
可选偏位：质心累加N、Σx、Σy；ROI结束后共享顺序除法求Cx、Cy；N=0时结果无效。先定义正常间隙与真值。
可选旋转：二阶矩累加Σxx、Σyy、Σxy，坐标中心化，乘法优先DSP；共享后处理查表／区间判定，不做像素级反正切。
可选极性：区域差分比较左右／指定小区域的亮度、颜色或模板分数；只有实际标记清楚、方向判据通过后启用。
按需多帧／双光场／边缘视图单帧或单光场不足时再评估窗口、曝光及延迟；完整Sobel、复杂形态学、大型神经网络不作为基线。
多个可见穴位共用一套特征提取和后处理，分别保存累加状态。穴位数量由实测视场决定；不按孔数复制整套检测器。
载带智检仪 / SYSTEM GUIDE 09

模块清单：具体加什么、由谁验收

点击模块展开输入输出与检查点。所有RTL由A组实现或接入，B／C组提供算法或实物参数。

底座 clock_reset / camera_cfg时钟复位与摄像头初始化

输入 → 输出：官方时钟、复位和初始化参数 → 各域运行条件。

检查与协作：保留官方底层；A组核对约束和复位释放，B组验证曝光增益改变后的成像。

A pixel_adapter / fixed_roi把像素接口与检测区域说清楚

输入 → 输出：ISP像素与同步 → 每lane坐标、ROI掩码和frame_id。

检查与协作：检查PPC排列、帧行边界、valid间断、复位首帧；B组提供实测ROI。

A gray_threshold / feature_accum灰度二值与统计

输入 → 输出：有效像素＋ROI → 前景位、面积／强度和、feature_valid。

检查与协作：位宽覆盖最大值，结束拍不能漏算；B组逐帧金标准比对。

A decision_engine单帧存在／空穴判定

输入 → 输出：完整特征＋阈值 → 类别、result_valid、frame_id。

检查与协作：不完整ROI不能当空穴；更换样品后旧结果作废；B组独立测试。

A view_mux / osd_overlay处理视图与轻量显示

输入 → 输出：对齐的原图／处理图＋匹配结果 → 含Logo与文字的视频。

检查与协作：可旁路；字模优先ERAM，OSD至少2—3级流水并对齐同步信号。

A→B result_bridge / frame_match跨时钟结果与显示关联

输入 → 输出：采集结果及DDR帧标识 → HDMI域原子快照。

检查与协作：握手／异步FIFO；动态显示时以正确帧配对验收，不能逐位同步多位总线。

B hole_detector / pocket_tracker孔位、相位与可信编号

输入 → 输出：搜索带像素＋时序／位移 → 孔中心、run_id、pocket_id、sync_state。

检查与协作：B/C组核对物理位置；注入遮孔、中断、滑移与手动移动。

B roi_generator / sync_fsm及时产生ROI并管理失锁

输入 → 输出：可信孔位／预测 → ROI及有效状态／暂停请求。

检查与协作：ROI须在使用前有效；说明预测误差与缓存；失锁不能沿用旧号。

C event_dedup / defect_fifo保留每个未决NG

输入 → 输出：有效检测事件 → 去重后的队首、高水位、满状态。

检查与协作：保存编号、缺陷类型、采样时间／位置、有效性与处置状态；测试相邻NG及全NG。

C motion_controller / recheck_fsm停车处置与恢复

输入 → 输出：队首＋位置＋控制参数＋复检 → STEP/DIR/EN及事件完成。

检查与协作：C组提供电平、脉宽、脉冲/mm与最坏停止距离；B组验证复检结果。

载带智检仪 / SYSTEM GUIDE 10

每加一个模块，都守住视频和时序

资源规范采用Lab 1为唯一工程底座。Lab 2／3提供参考思路，不能直接把整套功能叠加。

资源

存储用对地方

行缓存、字模、模板和队列优先ERAM；不在复位中逐项清空RAM。综合后检查实际映射，不能只看源码写了数组。

算术

高速路径保持简单

比较、加法树和控制分级流水；乘法优先DSP，变量除法集中在ROI结束后的共享顺序单元。

时序

约束正确才有意义

检查布局布线后的建立／保持时序、时钟与I/O约束覆盖。正WNS不代表未约束路径安全。

内部资源提示行动
Slice ≤70%记录增量，继续确认时序与功能；不是自动通过。
70%—80%审查新增模块占用与后续余量。
>80%暂停增加功能，优先精简OSD、确认RAM映射、共享后处理，再评估其他优化。
每轮保存LUT、Slice、FF、ERAM、DSP、建立／保持余量、约束覆盖、报告位置与可退回镜像。官方Lab 1报告的57.44% Slice只是参考，不是你当前工程实测；这些门槛是内部目标。

三组协作：让交付物接得上

团队A组负责FPGA集成，B组负责视觉与独立验收，C组负责机械硬件；与功能版本名称分开使用。

团队A

FPGA与系统集成

交付：工程、RTL、接口说明、仿真、资源／时序报告和镜像。
集成边界：顶层、引脚和时序约束由A组系统集成人统一合并。
现在：复现Lab 1视频与固化启动。

团队B

视觉与测试

交付：同平面标尺图、样本真值、调参／测试划分、公式、阈值、位宽、定点测试向量。
验收：分别报告正常误报、空穴漏检及失败样例。
现在：准备一种料号及其载带。

团队C

机械与硬件

交付：支架与导轨基准、照明、驱动电平与脉宽、位移校核、停止距离和干扰试验。
验收：实物稳定、编号对应和停靠误差。
现在：准备可调临时固定与测距条件。

B组公式＋向量 → A组定点RTL／仿真／上板 → B组独立对照 → 验收后合入
C组机械电气参数 → A组控制RTL → C组送料／停车实测 → 验收后合入
接口变化先更新04接口约定，再修改代码。每轮由人提供实物操作证据，AI用01模板整理独立记录；未测写未测、缺证据写待补证据，人工复核状态单列。

接入顺序与阶段出口

先让最小作品完整交付，再增加运动与闭环。以下是工作顺序，不表示已完成。

步骤本步新增／实验能继续的依据
1 · 视频复现Lab 1，稳定运行与固化启动实时视频、输入测量、本机资源时序及冷启动证据
2 · 视场毫米尺、同平面载带、固定与复装试验清楚可重复成像；据实选固定ROI与有效穴位数
3 · 算法真值与离线面积／亮度判定独立样本达到预先约定误报／漏检目标，定点向量准备好
4 · A集成接口 → 灰度／二值 → ROI统计 → 判定 → 显示同一镜像含处理视图、正常／空穴结果、Logo；稳定30分钟，建议3次冷启动
5 · 运动低速短带；电机关闭／匀速／启停及光源切换选定速度下图像清晰、视频不受干扰、实际位移可测
6 · B集成孔位 → 相位编号 → 动态ROI → 失锁恢复真值对应无未检出的错号；异常能暂停恢复，动态显示帧配对通过
7 · 停车实测制动 → 队列 → 高水位／溢出处理距离预算满足，停对穴位且未决事件不丢；建议至少30次定位停车
8 · C集成人工处置 → 复检 → 恢复与连续NG未修好保持停车、修好后按序恢复；建议20次完整闭环，统计净吞吐
每加一个RTL模块都单独编译、布局布线和上板验证。失败时退回上一稳定镜像；不等所有模块写完后才一次联调。
