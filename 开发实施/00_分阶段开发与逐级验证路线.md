# 载带元件智检仪 分阶段执行计划

> 2026-09-07用户批准修订。A视频识别版 → B连续检测版 → C停车闭环版。
> 本文规定顺序；02规定资源和时序；04规定接口、编号与队列；01和Word用于填写记录。批准计划不等于验收通过。

## 1. 八步路线

| 步骤 | 版本 | 要做的事 | 通过后得到什么 |
|---|---|---|---|
| 1 | A | 核对板卡、工具，跑官方Lab 1 | 稳定视频工程、本机时序报告和早期固化启动证据 |
| 2 | A | 测毫米尺、视场和固定支架重复性 | 可重复的单穴或其他有效检测区，不预设穴位数 |
| 3 | A | 一种元件的正常/空穴真值与单帧算法 | 样品对照表和最小离线金标准 |
| 4 | A | FPGA识别、处理视图、轻量Logo、结果文字及冷启动 | 可独立验收的A版 |
| 5 | B | 水平短带运动和首次电机干扰试验 | 可用的速度、曝光、实际位移与视频稳定性数据 |
| 6 | B | 相对编号、失锁、重同步和运动识别 | 可独立验收的B版 |
| 7 | C | 实测停止距离、NG FIFO、正确穴位停靠 | 可重复的定位处置能力 |
| 8 | C | 人工处理、复检、连续NG与恢复试验 | 可独立验收的C版 |

A版使用固定机位、固定ROI、静止样品和单帧判定；不存在/存在识别先闭合。极性、偏位、角度、多帧、双光场都不能阻塞已经可交付的A版。低成本运动试验可以提前做，以减少后续返工，但B/C验证项不是A版前置功能。

## 2. 步骤1 官方视频基线

1. 拍摄HX1P35A与PH1P35MDG324丝印，确认摄像头、排线和约束文件对应；不带电插拔MIPI排线。
2. 保留未修改Lab 1，复制出开发工程。使用现有1024×600配置，不先切720p60。
3. 在TD完成综合及布局布线，保存资源、建立/保持时序和约束覆盖报告。
4. 显示实物画面，测输入分辨率和输入帧率，记录HDMI输出模式。输入帧率不能用显示器刷新率代替。
5. 连续运行30分钟，记录错误计数、花屏、黑屏、冻结、撕裂和重启。
6. 按板卡流程固化并验证断电后自动运行，记录启动方式；A版整合后还需再做冷启动。

通过条件：本机可重复运行、无未解决视频异常、约束正确且时序通过；不以官方压缩包内的旧报告冒充本机测试。

## 3. 步骤2 真实视场和夹具

1. 固定相机、现有镜头、顶光和水平导轨。记录高度、倾角/垂直基准、镜头锁紧位置、光源和导轨位置。
2. 在元件同平面拍毫米尺。可在80、110、170 mm附近尝试调焦；记录实际距离和测量起止位置。
3. 记录画面有效宽高、完整穴位数、孔位可见性、边缘清晰度；如研究极性，再记录标记像素数。
4. 用实际模式验证ROI，不直接套商品20°视角或28 mm估算。先测后决定单穴、双穴或多穴。
5. 轻微横移并拆装后复拍，比较位置和分类是否变化；A版可限定固定ROI，完整畸变补偿视误差影响决定。

通过条件：正常件与空穴在选定检测区内可重复清楚成像，装夹可复现。B版进入编号前还须确认定位孔和P0/P1关系可用。同相机返修空间留待C版验证。

## 4. 步骤3 真值和离线单帧算法

1. 选一个具体料号和载带，登记每个物理穴位。正常件完整平放；空穴确认已经取走元件且无异物遮挡。
2. 真值标记位于检测ROI和定位孔之外，或用背面标记/照片映射。记录样品制造方式和确认人。
3. 调参与测试按物理样本或测试段分离，保存原始图像。初期建议每类至少30个独立样本；连拍同一件不能当成新增独立样本。
4. 先在固定ROI中以面积、亮度或简单特征完成正常/空穴判定，记录阈值、误报、漏检和失败样例。
5. 形成定点参考结果、位宽与测试向量。写RTL前填写04的接口表。

通过条件：测试前写明样本数、误报/漏检目标，独立测试达到本版目标；不以未解释的总准确率代替分类错误。尚未启用的偏位、旋转和极性不纳入A版必做项。

## 5. 步骤4 A视频识别版

1. 从Lab 1副本加入可旁路灰度或二值处理，保证可以直接看见处理后视频。
2. 加入固定ROI存在/空穴识别和文字。样品更换/图像不稳定时显示等待有效判定，不沿用旧结果冒充新结果。
3. 保留可辨认安路Logo，以小位图或ERAM实现；边缘检测不是A版强制项目。
4. 每加一个模块做综合、布局布线、时序检查和对应上板验证，填写资源增量表。
5. 同一镜像整合所有A版功能，连续运行30分钟；建议3次断电冷启动，不重新下载或手工补配关键参数。

### A版通过清单

- [ ] HX1P35A上MIPI采集、HDMI实时显示。
- [ ] FPGA处理后的灰度或二值视频可直接观看。
- [ ] 视频连续稳定，有对应工程及记录。
- [ ] 安路Logo和识别结果文字在同一设计中。
- [ ] 真实载带正常/空穴独立测试通过，结果不宣称覆盖其他质量项目。
- [ ] 资源及建立/保持时序通过，必要时钟与I/O已正确约束。
- [ ] 固化后冷启动运行，无需PC再次下载。

A版到此可独立验收。无需等待运动机构、失锁恢复或完整FIFO。

## 6. 步骤5 运动和电气干扰

1. 先使用保持元件的水平短导轨和可控送料，核验驱动接口、电平与供电。普通传送带的“可调速”不证明支持精确定位。
2. 先固定低速，例如实测约5 mm/s，再按效果逐步试更高速度；每次只改一个主要变量。
3. 对比电机关闭、匀速、反复启停、光源开关工况下的错误计数、闪屏、丢帧、重启及画面亮度。首次机械联调就做，不能留到C版最后。
4. 记录供电、共地/回流、布线和纹波测量条件；发现异常先定位电气影响。
5. 测运动清晰度、逐行曝光形变、有效检测行程、每穴可用帧数。先试短曝光、稳定照明或降速，再决定是否需要算法补偿。
6. 先测单帧；确有需要时才增加多帧，并按有效行程计算采样窗口、最大等待和超时策略。双光场不在本步必做。

通过条件：锁定一个可重复工作速度；视频不受电机启停干扰，运动误报/漏检达到预先填写目标。保持结构不会让元件离穴或制造未记录新缺陷。

## 7. 步骤6 B连续检测版

1. 登记P0、P1、初始相位和送料方向，建立“运行段标识+本段相对穴位号”。
2. 同一穴位只正式判定一次；正常受控暂停可保留可信编号，无法确认位移则进入失锁。
3. 实现失锁暂停、旧结果/队列冻结、受影响带段确认和重新建基准；不要求恢复整卷永久绝对号。
4. 采用动态ROI时解释其生成时刻；画运动框时验证检测帧与DDR显示帧对应。使用运动事件时间，不以延迟画面直接控制位置。
5. 对照物理真值测试运行、暂停恢复、孔遮挡、视频中断、滑移及手动拖动，记录容许观测间隔与重同步次数。
6. 顶部方向特征通过静态和动态试验后，可加入方向识别；偏位/角度需先定义允许间隙和测量真值。

通过条件：目标速度下完成约定长度试验且无未检出的错号；对失锁注入能暂停并正确恢复。先短段后500～1000穴运行试验，反复使用同一带段须注明。资源、时序和冷启动复测通过。

## 8. 步骤7 停车距离与NG队列

1. 在真实负载、速度和供电下，测指令到实际停止的响应时间、最坏停止距离、滑移和重复误差。
2. 检测到处置距离至少覆盖“速度×最大判定及控制时间+最坏停止距离+误差余量”；起点定义为首次有效采样位置，避免漏计多帧等待。
3. 按实测视场和可达空间决定检测/处置位置，不预设3～4穴位足够。窗口小则调整速度或布局，不跳过预算。
4. 默认逐个处理NG，运行段+穴位号去重；复检通过或明确隔离后才完成事件。
5. 高水位受控停车，剩余容量覆盖停止期间新增NG与判定在途事件；队列满故障不得静默丢弃继续运行。
6. 测单NG、相邻NG、间隔NG、全NG、高水位、满队列和失锁。重新编号前确认旧NG，不让旧号控制新运行段。

通过条件：实物真值与停车穴位一致。建议至少30次定位停车，目标误差由实际处置窗口填写；不把原±0.5 mm当成已有精度。报告停错穴次数和每次误差。

## 9. 步骤8 C停车闭环版

1. 选择可操作且可成像的处置位置；同相机复检须在视场、停车预算和操作遮挡试验后确认。
2. 人工补料/调整后按键复检，等待画面稳定；复检失败保持停车。
3. 当前事件结束后处理下一NG；恢复前核对编号仍可信，失锁则走重同步流程。
4. 建议连续完成20次检测—停车—处置—复检—恢复，测试连续NG和错误处置。
5. 测正常件误停、异常漏检、停错穴、失锁/重同步次数及包含停车和人工处理的净吞吐。复检不重复计产量。
6. 保存资源、时序、整合镜像、连续运行和冷启动证据。

通过条件：本版启用类别的检测与处置闭环可重复，未决事件没有静默消失。卷对卷、自动取放和双光场均不作为C版必需项。

## 10. 每次集成都做的事

- 明确本次新增模块和A/B/C所属版本；保留上一版工程和bitstream，官方例程不改。
- 记录LUT、Slice、FF、ERAM、DSP及相对上一版增量；保存布局布线建立/保持时序和约束检查。
- 功能与视频稳定性同时验证。新功能失败时可以退回已验收镜像，不靠忽略时序或丢弃事件通过。
- 对当前实现记录采样到判定延迟；涉及动态显示时另测采集到显示延迟。多帧复核记录最大延迟而非笼统“固定”。
- 验收表字段不适用时写N/A及原因，未测写未测；不能把空白默认成通过。

## 11. 扩展何时增加

| 扩展 | 开始条件 |
|---|---|
| 极性、偏位、角度 | 该特征可见，正常容差和真值已确定，有对应版本资源余量 |
| 多帧 | 单帧不够且可用时间窗口、最大等待和停车预算允许 |
| 滚动快门补偿或完整标定 | 实测误差妨碍当前目标，简单光学/速度/ROI措施不足 |
| 双光场 | 决定启用后再验证曝光时序、驱动和帧相位；不是A版前置 |
| 第二配方、缺陷地图、数据导出 | 当前版本完整通过，有时间及资源增量依据 |
