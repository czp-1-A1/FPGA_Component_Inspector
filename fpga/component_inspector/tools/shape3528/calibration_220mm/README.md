# 220 mm 样本与配方确认

先烧录已通过软件验证的 V11 实验镜像，确认输入1920×1080、输出1280×720/60Hz，固定同一镜头、220mm安装位置、焦点与光源。记录距离测量起止平面、曝光、增益、白平衡、图像模式及镜像SHA。

提供正常3528有件、真正空穴、定位孔、亮背景和双目标的代表图像，覆盖中心及边缘位置；每张注明真实类别。另提供同一检测平面的毫米尺，尺不进入分类样本。优先直接导出的RAW/无损图像，避免缩放、截图重采样和自动色彩修饰；手机拍屏仅辅助确认显示与装配。

已有数据不必删除或全部重采，只增加本条件样本。当前100灰度、80边缘及旧V10尺寸/面积/侧参考配方是调试初值；工作距离变化后不能把旧配方或2/3比例当作标定结果。先从新样本测量720p px/mm、目标宽高和面积，再分别复核亮度/填充/侧参考分布，并用另外的标注样本复测。缺少新样本时保持PENDING，不编造通过。

最多双目标、有件/空穴与模型诊断沿用V10；SIZE/ASP/FILL/REF不等于已经标定的偏移、旋转、立起或翻面质量分类。相机采集FPS独立测量，不把60Hz输出当作60FPS输入。
