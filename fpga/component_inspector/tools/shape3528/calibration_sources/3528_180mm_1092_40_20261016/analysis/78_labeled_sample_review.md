## 阈值修改主线

以下是当前代码实际基线，不是本轮已经重新测定的新参数。尺寸单位统一为1280×720处理像素；内部640×360尺寸需乘2，不能与1920×1080相机原生像素混用。

| 参数组 | 当前值 | 本轮优先核对方向 |
|---|---|---|
| 主体灰度分割 | T100 | 用旧有效有件标定和本批正常/翻面对照，检查主体是否完整、是否碎成多个轮廓；不因显示开边缘就改变真值 |
| 正常主体尺寸 | 长44—78、短36—72 | 按当前视野从实际主体轮廓核对上下区；WAIT图同样纳入离线尺寸估计，结合已知有效区/规格书尺度及旧有效CAL交叉检查，不照搬旧分辨率数值 |
| 正常比例/填充 | 1.05—1.55、至少85% | 重点看静止视频的FILL变化；正常和异常门限分开，不能为了减少闪动让所有异常都成正常 |
| 有件待复核包络 | 长44—86、短36—76、比1.05—1.8、填充至少75% | 核对侧立投影短边/比例及翻面分割是否超出包络；目标是先保留有件并标摆放异常，不能整体放宽后把大圆孔当器件 |
| 小孔灰度/尺寸 | T80，长短边6—10 | 真空穴与大定位孔分别验证；保持大小孔间的拒绝区，不将所有不匹配物体直接归空穴 |
| 定位孔尺寸 | 长14—18、短12—18 | 同图大孔为排除真值；孔不占器件结果，侧立件应与圆孔的形状特征区分 |
| 暗背景参考 | 75%暗像素；有件远参考、空穴局部参考 | 用REF变化与邻件/载带末端/倾斜场景核对，避免参考条污染让正常有件反复复核；不直接取消载带参考 |

调整顺序：先正常件/真空穴/定位孔可分范围，再侧立/翻面等有件复核容差，最后检查同区混合与静止波动。每一项建议写清“原值→拟值→有效样本依据→大孔/空穴反例影响”。若仅调阈值仍不能解决碎裂轮廓或选点，明确指出所需的最小规则修改，另让用户确认，不悄悄转成新的算法工程。
