## 实物复测

1. 烧录本目录镜像；确认 ANLOGIC 标志下方出现 `ER x LP xxxx WS xxxx`，借此区别旧镜像。
2. SW1、SW2 都拨下进入 RAW，等待2秒后轻轻移动载带，观察10秒。
3. 仅 SW1 拨上进入 GRAY；同样等待2秒并移动载带观察10秒。
4. SW1 拨下、SW2 拨上进入 EDGE；同样观察10秒。
5. 两个 SW 都拨上进入 GRAY+EDGE；同样观察10秒，再拨回 RAW 确认恢复。可重复一轮。
6. 若 EDGE 卡住，先拍全屏，确保标志下的 ER／LP／WS 和页脚 FR／SEC／OF／VF／UF 清楚；随后切回 RAW，记录是否自行恢复。即使 FR/SEC 在变化，也以实际移动载带是否显示为视频更新依据。

## 诊断字段

三个新增字段均为十六进制。ER／LP／WS属于上一 AWB early epoch，由现有 CDC mailbox 一起传输，OSD 在显示帧边界一起锁存；切换后先等2秒再读稳定值。OF仍是独立的累计计数，不能说整组52bit都来自同一个视频帧。

| 字段 | 含义 |
|---|---|
| ER | 4bit拒帧原因，可按位相加；见下表。0只表示没有记录这四种原因，不能单独证明完整帧已写入并发布。 |
| LP | Sobel输入端最短行首间隔，单位是CSI处理时钟拍，按1024像素行计数。0表示未量到两个行首，FFFF表示饱和。它不是摄像头原生行时序的直接读数。 |
| WS | EDGE等待行读取信用/出口允许的最长连续等待拍数。RAW/GRAY应为0；FFFF为饱和。 |

| ER位值 | 来源 |
|---|---|
| 1 | 边缘行缓存拒帧 |
| 2 | 摄像头配置无效 |
| 4 | CSI lane异常 |
| 8 | ROI/输入帧完整性保护拒帧 |

例如 ER9=缓存拒帧+完整性拒帧，ERA=配置无效+完整性拒帧。切换瞬间的旧帧可能被主动拒绝；关注模式稳定后是否持续增长VF、持续卡住及ER稳定值。
