核对首末像素、全部有效行、同步区间、正极性和TMDS运行偏差。参考接收器在运行前冻结。
另在B冻结树运行相同生产PLL源码的原厂频率模型短测试，测得74.25/371.25MHz、5:1。
这两种测试不合并称为真实PLL＋全帧串行链验证；板上实际频率/锁定没有测量。
