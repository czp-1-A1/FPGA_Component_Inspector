## 实现内容

- 相机仅改0x3208/09=0x0780、0x320A/B=0x0438；保持读取范围、RAW10双Lane显式设置、1×1采样、初始化顺序、曝光/增益和四键行为。厂商源表、来源SHA及逐项比对在source_audit。
- 统一1920×1080/PPC4，保留RGB888每拍四像素和原像素顺序。每帧2,073,600像素、388,800个128位字；每行360字。帧计数、坐标、Sobel组地址按几何参数计算位宽，完整帧发布、坏帧拒绝和帧尾直通保留。
- 写侧整行信用：FIFO已用≤120才开始360字的一行，留32字。读侧独立保留240字突发及reserved≤271门槛，预填充360字；首帧会发出两次突发。尾突发及四槽边界按MC实际16位地址单位核对。
- 保留主PLL的系统/相机输出。独立HDMI整数PLL链生成74.25/371.25 MHz，5:1；锁定等待和像素域复位同步释放已实现。失锁由持续运行DDR域禁止新读、清点旧响应、排空后复位FIFO，重锁后从干净帧边界启动。
- HDMI：1920×1080p30，2200×1125；HS区间2008～2052，VS1084～1089，VIC34。绿框[704,1216)×[412,668)，青框[920,1000)×[500,580)，统计6400像素；顶栏/字模/Logo保持，页脚下移480，底板y=984。尺寸/FPS来自实际输入监测，不能用HDMI刷新率替代采集FPS。

## DDR50 MHz方案及限制

物理参考仍接50 MHz。厂商PLL计算所得PLL0 N2/M32，VCO800 MHz，DDR时钟266.667 MHz、控制器/用户时钟66.667 MHz、配置时钟50 MHz；PLL1参考66.667 MHz，N2/输出分频24。tCK3750 ps、DDR2-533C、CL4/CWL3、刷新2080周期（7.8 us）已在RTL、控制器define和IP生成参数中一致调整。详见source_audit/README.md及audit.json。

读写有效载荷为373.248 MB/s。理论DDR峰值不能证明实际带宽；仿真已包含竞争、周期服务间隙和暂停恢复，但没有验证DDR PHY、训练、真实刷新命令合法性及板级信号完整性。**必须完成物理DDR写读与压力测试后才能判定底座通过。STA告警消失不能替代该测试。**
