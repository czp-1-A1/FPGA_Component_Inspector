# P02 有件/复核分类候选：烧录与复拍

P02针对本轮已确认的问题，把T100有件的周边暗参考条件改为同一器件内部表面条件；尺寸、比例、填充及弱T80复核保留。正常正面应显示“有件”，背面、短侧、长侧、背侧应保持“待复核”。当前已通过仿真，实物效果需此次复拍验证。R13及P01原版保留用于回退。

## 使用

1. 从`D:/fpga_download/`选取本次交付回执指明SHA的`P02_...bit`，人工烧录；确认标题`DETECT P02`，SW4上拨检测页。
2. 保持本轮条件：EXP1092、GAIN40、MODE0、WB100/100L，等待CFG1、V1、WAIT0稳定；无需启动新计数段。
3. 按这次顺序：**正常→背面→短侧→长侧→背侧**，每种停稳约2秒，拍清全屏、目标框和PRB1/2。正常件在ROI内稍作左右移动，再停稳一次，可检查位置变化后的表现。不要为了匹配结果改变曝光、姿态真值或更换bit。
4. 保留异常情况的原视频，不需手抄。短侧、长侧的C/L/R/T/B为零可能是宽度不足32的明确无内窗状态；不是原生灰度为零。

## 判据和读数

P02仍按原T100对象框计算C/L/R/T/B。四周任一方向明显暗于中心，视为未能证明正常表面；取四周最低值以覆盖不同方向的背面暗条。内部计算将每格2×2灰度截成5位，再求区域均值，条件为中心达到原前景阈值，且`5*min(L5,R5,T5,B5) >= 4*C5`。内部窗口缺失或不完整时保持复核。原始8位诊断均值保留显示，避免把8位显示值直接当作5位计算值。

|字段|P02含义|
|---|---|
|RS首位|C/E表示只读中央探针窗口有效；8/A表示该探针窗口不可用；E/A带弱T80来源。|
|RS第二位|1尺寸、2长宽比、4填充，均沿用原规则；**8现表示内部表面/采样证明失败，不再表示外侧暗格失败**。可按位组合。弱T80的F仍是原特殊复核码，不能拆为四项实测失败。|
|C/L/R/T/B|原8位处理灰度均值，HEX显示，来源同一源帧、同一首有效显示目标；不是手机亮度，也不是传感器RAW10值。|
|DARK|保留的原外侧暗参考格数，每侧两位HEX、FF饱和。P02有件质量判定不再依赖它；空穴/定位孔路径沿用原规则。|
|FRAME / SRC|沿用原元数据有效及源帧号。FRAME0或SRC0的过渡画面不用于拟合分类条件。|

PRB1/2仍分别测上/下ROI从左到右首个有效显示目标。有效首目标为空穴或未知时本行显示零，不跳过它去测另一个器件。显示用P01中央小缓存保留，所以目标移出中央区域时可能没有PRB内部读数；**P02分类缓存覆盖整个双ROI及采样上下文，对全部8个真实候选均生效**，不会只优化一个目标。
