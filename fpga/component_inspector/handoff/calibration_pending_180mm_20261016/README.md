本次已授权上传“待标定”阶段。后续配方定版、正式发布、烧录和再次推送按用户届时指令执行。本交接不授权扩展黑色/透明器件、新型号、AI分类器、第五模式、自动曝光，或重写MIPI/DDR/HDMI与识别架构。不要通过关闭有效性保护、放宽坏帧判定来消除WAIT。

### 1. 先收RAW/阈值100读数，不要求四模式各拍整套

已有基础库：`../../tools/shape3528/calibration_180mm/session_1092_40_20261015`，六张包括有件、真正空穴、横纵标尺、混合和背景；手机拍屏用于辅助定位，不能当作原始像素图。尺面与器件面大致同高，未精测高差，且横尺有环形反光，不能宣称精密标定完成。

接收用户发来的新观察照片，先列出已收到的类别和缺失读数，不重复索要已有整套普通照片。优先在RAW模式（观察阈值100）采有件、真正空穴、定位孔；上下两个有效区均应覆盖。记录每张的区域、物理穴位编号/位置、人工真值、EX/GAIN/WB/灯档、CAL读数、CLIP及WAIT原因。

“完整且单独”指把**一个待测特征**完整放进粉色64×64外框，避免混入邻近器件、孔或载带外亮背景，确认CLIP=0。黄色16×16框是局部亮度测量，本来就小于器件。**CLIP=0只是必要条件，多目标即使CLIP=0也不能直接作为单件尺寸。** 若固定框无法隔开定位孔与载带外亮背景，记录限制，再做最小必要的测量工具修正，不能把混入的背景算成孔。

CAL1中心(640,320)、外框[608,672)×[288,352)、核心[632,648)×[312,328)；CAL2中心(640,516)、外框[608,672)×[484,548)、核心[632,648)×[508,524)。可移动载带到测量框，不要为了迁就样本随意改两个识别有效区。

读取核心M/MIN/MAX/SAT及外框W/H/A/CLIP。SAT是处理后灰度=255的像素数（核心共256像素），不是传感器RAW10饱和统计。底部旧MEAN/MIN/MAX来自固定中央80×80区域，不能替代CAL目标读数。

持续WAIT先拍清原因文字与L/F/I/G/VF/UF，独立排查帧完整性、配置世代与结果绑定。修复旧格式F误报不能证明其他WAIT根因已解决。不能靠分类阈值放宽掩盖WAIT。

### 2. 根据实测改识别配方

确认器件、空穴与定位孔的宽高、面积、纵横比、填充率、侧参考暗区；检查是否混入相邻特征。CAL使用与识别器一致的灰度及2×2平均阈值规则，但报告换回720p坐标单位：W/H步长2、A步长4；外框内统计的是前景联合范围，不是自动分离后的单目标。

注意单位：`inspection_region_config.v`的RECIPE0/RECIPE1用于640×360内部平均图，若从CAL的720p数值换入，宽高除2、面积除4；已经是内部单位的值不能再除。不要把OSD扩边当器件尺寸，不用单一2/3系数或仅凭180/220距离比推测最终配方。

核对真实分类路径后再修改。顶层历史CLASS_THRESHOLD=58不等于局部识别前景阈值100；不要改错参数。灰度100、Sobel80和原纵横比/填充判据作为起点，修改须有样本读数支持。Sobel80当前主要服务边缘显示，不要声称已标定边缘分类算法。

输出配方表：参数名、旧值、新值、坐标/面积单位、对应样本、采用理由及上下区差异。若类别仍重叠，要如实说明样本或判据不足，不能扩大范围后直接宣布通过。

### 3. 用独立样本验证配方

另取实际穴位和摆放位置，区分标定集与验证集，不能同一穴位换角度拍照就当独立验证。检查：有件识别、真空穴识别、定位孔排除、背景NO TARGET、上下区与双区混合。人工标真值，记录误检/漏检/不确定，不以旧分类文字为真值。

此时再检查四模式下的显示及分类一致性、框坐标、参数切换后的失效与恢复、坏帧/停CSI/复位、迟到结果、无旧框错帧及撕裂。四模式回归不意味着必须给每个模式重新建立完整照片库；出现差异时再针对性补拍。

软件仿真通过与实物配方通过分开写，没有实物验证不能写180 mm标定通过。
