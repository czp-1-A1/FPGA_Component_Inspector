# P01 分类测量版：烧录与拍摄

本版在R13独立副本上增加只读测量，保留R13的分类规则和计数。仍显示“待复核”是预期；这次要取得原因与器件内部结构读数，再决定分类修复。正式镜像、SHA和验证结果以同目录交付回执为准。

## 拍摄步骤

1. 烧录本包P01 bit，确认顶栏为`DETECT P01`。R13回退bit随包保留。
2. SW4上拨到检测页，维持当前成像条件：EXP1092、GAIN40、MODE0、WB100/100，拍清CFG1、V1及FPS。测量不需要启动新计数段。
3. 将待测器件放在上方ROI中央竖线附近，上下居中，停稳。底栏`PRB1`对应上路从左到右首个有效显示目标；`PRB2`对应下路。两个框同时存在时，确认本行所属的左侧目标就是要标注的姿态。若首个有效目标为空穴或未知，本行显示零；只有首槽无效才选第二槽，不会跳过有效空穴去测后方器件。
4. 按本轮已给的顺序，正面→短侧→背面→长侧→背侧，每种停稳约2秒；可连拍一段。拍清目标框、顶栏及底部两行PRB，保持光照和曝光/增益一致。无需手抄数值。
5. 正面、背面和背侧停稳后，PRB1的`RS`首位应为`C`或`E`，表示内部窗口可用。若为`8`或`A`，将目标移回ROI中央，仍拍下该状态；短侧/长侧过窄导致该状态属于预期。

## 读数含义

|字段|含义|
|---|---|
|RS|第一位表示目标/内部窗口有效及是否弱T80来源；第二位为原分类原因。第一位C/E表示内部采样有效，8/A表示有件但内部窗口不可用。E/A带弱T80来源标志。|
|原原因第二位|1尺寸、2长宽比、4填充、8周边暗参考，可按位组合；弱T80来源时F是原分类器的特殊复核码，不能解释为四项均实测失败。|
|C / L / R / T / B|当前目标中心、左、右、上、下区域的8位处理灰度均值（0–255，1280×720处理域，不是传感器RAW10）。中心16×16处理像素，其余各8×16或16×8，来自同一源帧2×2均值缓存。|
|DARK|左/右原暗参考格数，各两位HEX；FF表示达到或超过255，原通过门槛为240（F0）。这是原窗口读数，没有降低门槛。|
|FRAME|该显示帧测量元数据的有效标志；每个目标内部窗口还需看RS。|
|SRC|整份元数据的源帧号，沿用原R13的同槽/epoch发布。|

PRB各数值采用十六进制；顶部OBJ的W/H/A沿用原十进制。某行没有有效有件时显示零。窗口不完整或窄于32×32处理像素时，C/L/R/T/B清零，RS会明确标识，不复用上一帧读数。

测量来自选中目标本帧的位置，而非旧CAL固定空间窗口。手机视频用于读屏和确认姿态，不把拍屏像素亮度当作FPGA原始灰度。

## 本次要回答的问题

- 正面被复核，究竟来自暗参考条件、弱T80来源还是其他原原因。
- 正面与背面/背侧在目标内部的中心和四周分布，能否形成有物理依据的区分条件。
- 侧立已有的尺寸/比例异常仍保留，新增判据应让正常件放行，并保持背面及侧立复核。

源码、原测试和失败记录均随完整包保留。R13原版及正式工程不被此测量版覆盖；本包不自动操作JTAG或Flash。
