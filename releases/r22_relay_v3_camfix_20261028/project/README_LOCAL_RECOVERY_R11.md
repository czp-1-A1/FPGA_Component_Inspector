# R11 local recovery contract (before implementation)

Baseline is the delivered R10 candidate_r4. This copy is the only implementation writer. All old freezes, test answers and images remain immutable.

1. Default-off LOCAL_RECOVERY preserves the old 57 contracts. Production enables it explicitly in the board wrapper. No classifier, original page, ROI, clock, constraint or pixel-cache change.
2. Keep the existing eight-source-opportunity ordered grace, so actual short returns retain their physical sequence. After that, an armed uncounted missing identity is quarantined locally, not CHECK. It no longer blocks later real pending crossings. Counted identities keep IDs; no missing target creates an event.
3. Quarantined identities retain their actual last observation, arm and bounded association displacement for a late actual return. They are excluded from order and classifier reservation until a unique actual result returns. Returning once can emit at most once. Retire after bounded retention or proved downstream travel; no indefinite stale RAM identities. Per-observation ambiguity skips that observation without discarding other unique same-frame matches. Integrity/config/bad-frame/reverse/overflow faults retain fatal protection.
4. Once an unconfirmed identity is bypassed, freeze uncertainty_from=total+1. Later numbers are explicitly RECORD numbers with physical sequence unconfirmed from that point. Never reserve a phantom physical pocket or increment totals from pitch. This warning persists through actual recovery until new-run/full-clear. It is not proof that a missing real pocket existed; a stale candidate may also be responsible.
5. Keep the 256-bit metadata and all CDC widths. Only LOCAL_RECOVERY packets reuse the inactive ROI's low nine object-ID bits for uncertainty_from (zero means no gap); active ROI's 18 ID bits and every other field remain unchanged. Renderer reads warning before normalizing active IDs. Original page does not read this extension. Version label R11, persistent yellow warning and R-prefixed record labels prevent shifted records being represented as exact physical IDs.
6. Accept only actual typed P/E observations from proved source frames. Prediction is association/retention only. Do not silently count first observations appearing solely downstream or guarantee arbitrary speed. Fast missing true EMPTY15 still needs actual source-evidence validation.

Required directed evidence: same-vector old CHECK/C4 sensitivity; short gap restores exact order without warning; long gap continues later actual crossings with warning; late return without duplicate; repeated display/frame; pause and new run/full clear; both directions; unknown/false candidate does not create count; locally ambiguous observation does not discard independent unique observations; multiple gaps and 300 capacity. Native RAW path and source-frame/metadata/pixel binding, original-page equality, all old immutable tests; final SYN/PHY setup/hold >=0, TNS0 and full constraints audit.
