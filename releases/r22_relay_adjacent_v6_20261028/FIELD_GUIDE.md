# RL6 连续空穴联调说明

本版针对RL5三连空穴中4号在停车后失去实际位置、最终F6的问题。原视频证明是位置失联，尚不能确定失联来自图像分类、候选筛选还是编号关联。RL6增加故障现场记录，并修正相邻目标交接及停车后搜寻。是否解决这条实物载带的问题，须由新版录像确认。

## 接线与操作

沿用现有接线：右边J2第1脚为FPGA球位V2，输出3.3V高电平允许送料；继电器由板上5V供电，J2第11脚5V、第12脚GND。继电器保持此前已验证的高电平触发。集成版不使用LED。原引脚约束、SDC、相机初始化保持。

K1：单击开启新一轮，清旧编号与待处理队列。开始前，左站和计数线前方应没有上轮遗留载带，首穴从屏幕右侧进入。

K2：运行中暂停/继续，保留RUN、计数和待处理空穴；待机可手动电机启停。K3：单键清零并停止。K4：停止并保留结果。SW3：上停止，下启动新一轮，无需双键清零。

保持单排料道，从屏幕右向左。计数ROI X448..831，左站内部ROI X64..447，Y240..399。屏幕保留右侧计数框、左侧琥珀色补件窗口和实际检测框，辅助线仍隐藏。补件窗口X80..240，目标160，触发192，提前32；范围与RL5相同。

## 本版动作

1. 队首实际到触发位置后停止电机，等待稳定并保持完整1000ms。
2. 当前穴完成后进入S6，电机保持停止，等待下一编号的新图像测量。下一穴已在80..240内：直接确认稳定并再保持完整1000ms；下一穴还在右边或尚未到站：恢复送料。
3. 同编号实际位置超过150ms未更新，进入S7/F6，在电机停止状态下额外找回最多500ms。已有待处理EMPTY编号不因普通候选缺席立即退休；搜索提示在停止时不继续沿旧速度外推。保留半节距约束，提示半径最高20px。
4. 只有同RUN、同编号、当前图像帧的真实测量连续3次稳定，才退出S7。随后重新确认稳定、重新计满1000ms；丢失前已保持的时间不累加。每个队首只允许一次此类恢复。
5. 500ms仍找不到、同一穴再次失联或出现编号/方向/图像等硬故障，进入S4并保留队列。不会通过跳过空穴、拿预测坐标作实际位置或把邻穴当目标来继续。

S7显示F6是正在找回；S4/F6才是最终锁定。S6/S7已用于自动流程状态，暂停/手动模式由底部U区分。上方V0时X显示“---”，旧X不再冒充当前有效位置。

## 底部诊断行

示例：`RD Z1 E1 F6 R0001 N004 T000025FB A96 DC4 CE8 S2 W0 U1`。数字均为十六进制；例如A96=150ms，N00B=11号。诊断在第一次位置失联时冻结；同一编号恢复后仍保留，便于录像。新RUN/清零会清除，新队首的新故障会更新。

| 字段 | 含义 |
|---|---|
| Z | 0实时记录，1故障现场已冻结 |
| E | 1实际位置超时，2相邻队首等待超时，3其他硬故障 |
| F | 此次记录的故障码；恢复成功后仍可保留6，不等于当前上方F |
| R | 控制器RUN |
| N/T | 左站最近完整处理的数据包查询编号/32位源帧号；交接时可与上方当前队首不同，不应混为同一帧 |
| A | 捕获时距上次有效位置的毫秒数，最高255 |
| D | 对这个查询编号采样的检测阶段标志，见下表；提示编号不符时清0 |
| C | 对该数据包的关联/发布标志，见下表 |
| S/W | 左站计数器状态/原因码；不是上方继电器S状态 |
| U | 当前模式：1自动、2暂停、3待机手动开、4待机手动关；该项随显示帧更新，不冻结 |

| D位 | 含义 | C位 | 含义 |
|---|---|---|---|
| 7 | 此帧存在搜索提示 | 7 | 仍有该编号轨迹 |
| 6 | 提示附近出现初选EMPTY | 6 | 找到实际查询目标匹配 |
| 5 | 提示附近出现初选PRESENT | 5 | 当前关联帧可信 |
| 4 | 最终四候选中保留附近EMPTY | 4 | 存在阻止发布的上游编号缺口 |
| 3 | 最终候选中保留附近PRESENT | 3 | 左站处于RUN |
| 2 | 提示候选占据保留槽 | 2 | 左站处于HOLD |
| 1 | 检测结果就绪 | 1 | 查询附近候选与原EMPTY类别不符 |
| 0 | 主结果未分类 | 0 | 查询关联出现多匹配迹象 |

D只是提示附近候选的被动记录，不是新的位置真值；C0是关联阶段线索，也不能单独确定唯一根因。必须组合源帧号、N、D、C、上方状态及实际载带画面分析。

## 请按这个顺序复测

先不补件、不触碰载带，固定一个速度，拍三连空穴从进入计数框到全部处理完的完整画面，确保上方RL6状态行和底部RD行均可见。再分别测试单空穴、双连空穴以及快/慢两档，每档至少重复3次。不同速度之间再调速，方便分组比较。

通过条件：每个EMPTY编号各完成一次S3，保持后自动处理下一穴；Q最终归零并继续送料。相邻穴同时处于宽框时，电机连续停止数秒、上方N逐个变化是预期行为，不是卡死。若出现S7，继续拍至少2秒；若最终S4，继续拍3秒并保留完整RD行，先不要K3清除诊断。

不需要手工解读RD各位；录像拍清上、下两行即可，由我们结合载带画面分析。

本版是宽范围停车和队列连续性联调，尚无吸嘴、实际补件确认或速度自适应，也不表示±1mm已达标。既有弱RAW280反光漏检边界和上游缺口保护仍保留；重定位不是对所有F6的保证修复。

新增压力测试发现：穴距40px、突然以24px/帧运动时，在第一次停车前就出现主计数类别/编号顺序错误；同一输入在RL5也完全同样失败。此项单独归档为失败边界，未算通过，不能宣称任意高速都可运行。请先用中低固定速度验证连续停车，再分组提高速度；若先出现计数顺序错误，应处理主跟踪速度边界，不能靠放宽补件窗口解决。此处像素/帧是仿真条件，未经实物标定不能直接换算成你旋钮的档位。
