## 四模式操作与结构

| SW2 | SW1 | 画面 |
|---|---|---|
| 0 | 0 | RAW 原色 |
| 0 | 1 | 灰度 |
| 1 | 0 | 原色叠加橙色边缘 |
| 1 | 1 | 灰度叠加橙色边缘 |

两位开关作为一组，经两级同步并稳定 20ms 后提交。参数从顶层传到 observation_controls、isp_top 和 roi_sobel_view，单独修改叶模块默认参数不能代替顶层配置。SW1/SW2 仍用 A4/B4，原 SW3 和四键操作保持 R58。

原四视图实现一直保留在 RAW_EDGE_ONLY=0 分支。恢复该路径后，保留完整 RGB 的三行缓存实际增加 5 块 ERAM；四个灰度行仍保留。综合网表逐个核查了 96 位 RGB 输入、5 个 20 位 RGB RAM、4 个 40 位灰度 RAM、原单字库、两列 ID RAM 和检测队列。没有降低像素精度或缓存深度。

识别、分类和计数仍接显示处理之前的 post_rgb，橙色边缘和灰度仅用于视图。计数/停车 config_tag 仍为图像配置与白平衡，不包含观察模式；切换视图不生成新 RUN 或清零命令。原帧取消、背压和缓存过载保护保留。

## 双列、蜂鸣器、延迟及对接接口

两列独立编号、总数、空穴号及原状态记录保持；主计数器和密集检测器源文件字节未变化。蜂鸣器沿用 R58：任一列连续五个有效空穴后锁存报警，C12 低有效，2kHz、响 200ms/停 300ms 循环，板载 SW5 须接通。清零或新 RUN 解除，暂停类操作保留报警。原电机注册输出和双报警联锁保持。R58 已将定位故障与真实坏帧分开；移植时应保留这条接线。

右上角蓝色 LAT/LAG、粉色 SRC、16×32 字号保持。LAT 使用同一帧的 RAW SOF 时间，到 OSD 后实际 HDMI 首有效像素重新测量；包含此后的读出、ISP、缓存等待和扫描，不包含此前曝光、HDMI 后端及面板响应。重复图像每次显示重新计时；无效、未来或过期标签显示横线，时间整圈回绕不会使过期旧图恢复有效。

SRC 是 32 位视频来源号，按 10 位十进制显示，与从 001 开始的穴位编号独立。LAG 是最新来源号与显示来源号的差，最多显示 999f。时间为公共 32 位微秒时基，两级同步后的注册 Gray；0.1ms 显示粒度不代表面板光学延迟测量精度。

R59 未修改以太网协议或记录模块。原分类元数据仍为 1143 位，双列计数记录仍为 512 位；R58 的 65 位采集旁带为 {valid,source_frame[31:0],capture_us[31:0]}，绑定相同的帧、槽位和 epoch。不要把视频来源号当穴位编号，或把旁带直接拼入既有协议字段。队员合入需保留 ISP、video_in、video_out、顶层邮箱与 OSD 的完整标签接线，分类迟到不能改写图像来源。

## 验证依据

最终源码对应 30 项验证，按实际编译输入 SHA-256 绑定：20 项 R58 同输入结果、4 项四模式预检、6 项本候选执行结果。四模式预检包括 4 个完整 1920×1080 RAW 帧，四种视图均有两列同时密集目标、相同帧标签/分类绑定及静止零误计数。它是 RTL/模型验证，不能代替实板光学验收。

还包括四模式逐像素及 128 位打包、缓存尾行/背压/取消恢复、13 次实际 DDR/FIFO/相位/OSD 显示帧及外部时间基准首像素比较、560640 个界面 RGB、第二列 112 个完整字形行、196864 次字符对照、原计数停车、生产五连故障碰撞、计时回绕及旧界面回归。A/B 界面预览 SHA 相同，显示输出保持。

最终物理审核要求 Routed/Both Slow and Fast、setup/hold 非负、两项 TNS 均为 0，并核查 44 有效最大延迟、精确 9 条已移除显示路径约束、原 20+新 64 位 Gray 及两级扇出、邮箱、四键/SW3、电机/双报警、C12，以及两位模式开关的实际 A4/B4 和两级同步扇出。原邮箱 9ns 预算保持，新增返回路径沿用 R58 C 的 9ns 修正，避免物理合并令牌寄存器后的约束覆盖。

## 实板验收与重建

先确认唯一 bit 的 SHA 与校验清单一致，屏幕为 INSPECT D3 R59、两列统计及右上角均完整。依次检查四个开关组合的图像和橙色边缘；让两列同时有目标并移动，核对各自编号、总数、空穴号及状态；制造单列五连空穴，核对停机、声音节拍、清零/重新启动。观察新帧 SRC 更新、重复画面 LAT 增长及无效横线。所有实际发声、光学识别和停车精度由人工实板验收，本任务未操作板卡、电机或继电器。

源码全量 705 输入见 R59_FROZEN_INPUTS.json；重建命令见 README.md。新构建需要本机 TD/ModelSim 与许可证，并重新审核最终物理报告。验证辅助脚本保存了本次真实机器路径，迁移运行需调整路径；本包 PASS 不能用于另一次构建。
