# RL7：补件区左移与五连空穴报警

烧录文件：R22_RelayAuto_Left_V7_ShiftAlarm_20261028.bit。保持原接线：板右J2第1脚V2为3.3V高电平送料许可，继电器使用板载5V，J2第11脚5V、第12脚GND；不增加LED或蜂鸣器。

补件框从80..240改为72..232，目标从160改为152，停车触发从192改为184；整体左移8处理像素，宽度仍160像素。屏幕状态T098/A020分别为目标152/提前32（十六进制）。内部左检测区64..447、主计数区448..831和料道高度不变。

正常1～4连空穴继续逐个停车确认、完整保持1秒，再处理下一穴。相邻穴同时在宽框内时可连续停数秒，观察N依次变化、Q递减。保留RL6电机关断时一次有界500ms找回，找回后重新稳定确认并保持完整1秒；RD底部诊断仍保留。

本版新增：主计数区确认第5个连续EMPTY后，立即锁定送料关闭，屏幕显示红色 `ALARM 5 EMPTY - MOTOR STOP - K3 CLEAR`，状态为 `RL7 S4 FF`。这里最后一个F是十六进制故障码15。报警在右侧主计数确认时触发，不等5个空穴全部走到左补件区。

中间出现有件会重新累计连续段；分散5个空穴、队列中累计5个待处理空穴、同一穴重复出现在多帧，均不等于“五连空穴”。编号/RUN不合法时仍按原完整性故障停止，不将其算作第5个合法EMPTY。

报警后保留当轮结果和队列，不自动恢复，也不能通过K2或K4后手动开电机绕过。先拍清完整上下状态行；处理好载带后按K3单键清零停止，再安排首穴从右侧进入并按K1开新一轮。明确的K1/SW3新RUN也会重置报警、编号和队列，不用于继续旧队列。

按键沿用：K1新RUN，K2暂停/继续（待机手动启停），K3清零停止，K4停止保留；SW3上停止、下新RUN。正常报警清除后仍需清空启动区域，避免把上轮已进入区域的载带重新错编号。

建议先复测原三连载带的普通和慢速，检查是否完成到Q00；再用4连、5连、6连空穴：4连应正常处理，第5个确认空穴应报警停止。最后测试“4空＋有件＋4空”，不应五连误报。测试时不触碰/补件，录像拍清上方RL7及底部RD即可，无需手工解码。

实物停车新位置、五连报警、连续运行仍待这轮复测；没有实际吸嘴或补件完成握手，也不表示±1mm验收。主计数既有高速边界和弱RAW280反光漏检边界仍在，未通过跳过编号、放松类别或改计数器来掩盖。
