# R22 继电器自动停车 V2：右侧计数，左侧补件

本版针对 V1 现场 `S4 F6 Q2 ID001 X2C5`：队首位置在709像素失去更新，尚未到736触发线便保护停车，未完成1秒保持。第六次不能启动没有现场S/F码，不能直接判定继电器或板卡损坏。用户已确认实际送料改为屏幕从右向左。

V1冻结包、V1 bit及R22回退版保留。新版本只在新文件名交付；是否通过最终布线和交付SHA以本版 DELIVERY.json 为准。本说明中的像素初值不代表已经达到±1毫米。

## 布局和编号

同一画面、同一上方料道，坐标为1280×720处理图像像素：

| 区域/线 | 初值 | 用途 |
|---|---|---|
| 右侧计数区 | X448～831，Y240～399 | 原R22分类和全局编号 |
| 原计数线 | X640 | 形成全局有件/空穴记录 |
| 左侧补件观察区 | X64～447，Y240～399 | 独立观察实际到达的穴位 |
| 左侧二次编号线 | X256 | 对按顺序到达的每个穴位再次计数，确认与全局编号对应 |
| 停车触发线 | X176 | 对队首空穴发出停机指令 |
| 最终目标线 | X160 | 补件位置；距原计数线480像素 |
| 允许窗口/漂移 | ±8像素/2像素 | 待按实际毫米标定 |

画面方向：`补件目标160 ← 触发176 ← 二次编号256 ← 原计数640 ← 来料`。

原来下方的第二观察框改为左侧补件框，当前配置用于上方这一条料道。分类阈值、四向Sobel判据、原R22计数/中文/Logo保留。灰度缓存改为横向覆盖两个区域，并缩短到上方料道的纵向范围；没有靠取消边缘检查让左侧空穴通过。

右侧只把实际判定为空的全局编号加入最多32项队列。左侧独立计数所有实际穴位；两处从同一空区启动，使用同一RUN和源帧，按保持顺序的单向料流对应编号。视觉不能凭空证明从未识别到的穴位，因此现场仍需用已知有件/空穴序列核对两个计数前缀，发生原始编号不确定或前缀矛盾时停止。

每个左侧新编号还需与右侧已记录的有件/空穴类别一致，核对完成后该编号的位置才能触发停车。类别不一致报F4，不能把后一个有件穴当成原空穴继续处理。完全漏掉一个穴位且后续穴位类别相同的情况，仍不能仅凭两处计数在数学上排除；这也是首轮必须使用已知料序验证的原因。

不能只把右侧的ROI拖大：检测器只保留有限候选，已计数的目标可能被丢弃。本版为左侧队首保留候选位置，但保留预测只用于寻找目标；停车判断始终使用该源帧真实观察到的中心坐标。

## 接线和启动

- 右侧 **J2第1脚=FPGA V2**，输出3.3V控制IN1；这里“V2”是芯片引脚名，也恰好与软件版本V2同名，两者无关。
- 继电器使用已实测可由3.3V触发的5V模块，S1跳帽设HIGH；DC+接板上J2第11脚5V，DC−接J2第12脚GND，IN1接J2第1脚。保持原来的共地接法。
- 电机仍由四节AA电池供电；COM1/NO1串入调速板电源正极。控制输出高→继电器吸合、常开触点导通→送料；低→停止。集成版无测试LED，原其他引脚不重排。
- 三档机械开关由用户设置，使载带在屏幕中**右→左**。FPGA不能自动拨动这个机械开关。原相机按键功能保留，K1不是送料启动键。

首次上板建议：

1. SW3向上，确认电机停止、相机和R22文字正常；先设置机械方向。
2. 把**待编号的第一穴位放到计数线右侧**，建议先放在右计数区靠右处；计数线左侧至补件区应没有未编号器件/空穴。只有带材背景而没有穴位/器件可以；不要把一整段已经经过计数线的料留在左侧再从零编号。
3. 若有旧计数/待处理队列，先人工核对料段，再按原来的K3+K4约1秒全清。清零会丢弃该RUN未处理队列，不能用它掩盖实际漏补。
4. SW3向上约0.1秒后向下启动新RUN。S5先等待一幅可信的空区证明，通过后才进入S1送料；有未编号料段时FC停止，需要重新摆料、全清再启动。
5. 先用一个已知空穴、低速测试。记录全局编号、左侧L、停后X、S/F以及尺子测得的偏差。正常为S1→S2→S3→S1，最后自动恢复。

恢复时继续沿原RUN处理后续穴位。同一空穴不会因还停留在镜头里而再次入队。故障后的SW3上下不能静默抛弃旧队列；重开RUN报FA时需先检查未处理料，再明确全清。

## 运输等待和1秒

刚在右侧编号时，左侧可能完全看不到目标。此阶段允许运输等待，默认最长15秒，不再立即套用150ms位置过期。左侧实际看见并绑定该编号后，连续150ms拿不到新位置仍报F6停止；可信图像源连续150ms不更新也停止。

队首实际中心越过X176后，输出撤销送料；需连续3幅满足位置窗口和静止条件的实际观察，再从确认时刻开始完整1000ms保持。保持中漂移/过期/编号不确定不会自动恢复。初始提前量16像素不保证电机最终恰好到160；如停在窗口外，F8保持停止供标定，不盲目重启。

## 屏幕读法

新标识 `RL2`，例如：`RL2 S1 F0 Q02 N001 X--- L000 V0 T0A0 A010 W0DAC`。数字均为十六进制。

| 字段 | 含义 |
|---|---|
| S | 0待机，1送料/等待目标到站，2停后定位确认，3保持，4故障，5启动空区确认 |
| F | 错误原因，0表示无故障 |
| Q | 完整队列长度，00～20（十进制0～32） |
| N | 队首全局空穴编号 |
| X / V | 当前队首已经取得过左侧实测位置时V=1，显示最后实测X；未取得时V=0、X---。V不代替时间检查，F6时最后位置已经过期 |
| L | 左侧已实际二次编号的穴位数量，不是空穴数量 |
| T / A | 目标160=0A0，提前量16=010 |
| W | 本队首在取得第一个左侧位置前等待的毫秒数；到站后冻结，换队首清零 |

F1图像/计数器错误，F2图像源过期，F3方向错误，F4事件RUN/全局顺序或左右类别不符，F5队满，F6到站后位置过期，F7越过目标窗口，F8停后未能稳定在窗口，F9保持漂移，FA旧队列尚未确认便重开RUN，FB参数/许可或两处RUN/编号前缀矛盾，FC启动时运输区有未编号料，FD原始编号不确定，FE等待到站超过15秒。

左侧整区用于观察，实际补件位置是目标线。尚未增加吸嘴/取放执行器，本版实现的是送料、确认、停靠保持与恢复。

## 现场需要回传的证据

首轮请拍一段同时包含完整画面状态栏和料带移动的视频，记录停止时尺子测得的穴位中心误差。若报错，保留完整 `RL2 S/F/Q/N/X/L/V/W` 后再清零；另记录第一个穴位初始位置、是否确实右→左。不要只回传“停了”，因为S3正常保持和S4故障的后续处理不同。

至少先验证单个空穴、有件夹空穴、连续两个空穴、末端空穴，再测正常速度和重复停靠。最终±1mm、实际1秒保持和板载5V供电稳定性以实板测量为准。
