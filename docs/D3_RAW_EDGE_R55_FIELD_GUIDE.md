# R55：双列识别、计数、停车；RAW／黑白边缘显示

此版显示选择只有两种：SW2选择RAW原图或黑底白色边缘，顶部MODE分别为0和2。SW1不再选择灰度，也不改变显示配置编号。先停止送料，通过MODE和画面确认SW2两档实际方向，再开始测试。

黑白边缘图保留ROI、中文标签、编号及状态叠加。顶部GRAY/MIN/MAX等仍是识别特征统计，不表示存在单独的灰度显示档。识别所需的灰度、局部边缘算法及阈值继续保留。

## 运行控制

| 操作 | 行为 |
|---|---|
| K1单击 | 开始新一轮双列计数并允许自动送料；重新编号和建立队列 |
| K2单击 | 暂停／继续当前自动流程，保留计数和待处理空穴；待机时用于电机启停调试 |
| K3单击 | 清零并停止 |
| K4单击 | 停止，保留结果 |
| SW3 | 上停、下开始新一轮；无需K3+K4组合清零 |

按键长按只触发一次，松开后才可再次触发。新一轮开始前，首穴应在右侧计数入口附近，左侧补件区不要预留未编号料。继续当前队列使用K2，K1会新建一轮。

## 送料、接线与验收

屏幕中从右向左送料。上下两列分别识别、计数和编号，使用一个共用送料电机。每列有32个任务位置；补件窗口X=72..232，目标152，初始停车触发184；合格停车完整保持1000ms后继续。任意一列连续第5个空穴会报警停下。

继电器保持现有接线：开发板右侧J2第1脚V2为控制信号，高电平允许运行、低电平停止；继电器5V由板子供电。继电器触发选择保持已实测有效的高电平设置。此版无板载LED运行显示。

先在电机停止时确认RAW实时画面，再确认黑白边缘和两列ROI。随后以同一速度依次测试两列单空穴、相邻空穴、K2暂停继续、K3单键清零、SW3多轮重开、任一列五连空报警。录像需包含完整状态栏及停车后至少3秒。

软件和布线签核不代替现场验收。当前白色3528配方、速度适用范围、真实吸嘴补料、保持过程和±1mm定位仍须实测；RAW整链路检查的电机许可关闭，停车由独立控制／队列测试覆盖。资源、时序、bit哈希及实际签核状态以同目录RELEASE.json为准；没有正式发布回执时，本文件仅为候选操作说明。
