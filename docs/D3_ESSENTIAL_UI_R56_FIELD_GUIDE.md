本版软件41项及最终Routed双corner物理审核通过：18337 Slice（86.43%），setup +0.039ns、hold +0.020ns，TNS均为0。仍待实板验收；没有自动烧录或操作电机。

保留上下两列独立TOTAL/有件/空穴/待复核/LAST、各列8个空穴编号及页码、识别框与标签编号、补件窗口、FPS和输入监测分辨率、标识与简短版本。输出仍为1280×720；图中1920×1080为输入监测值。灰底仿真预览不是实拍。

调试参数、TR坐标/面积/源帧、内部RL/S/F/Q诊断行、调试页面已删除；右上角LATENCY/FRAME LAG不做。待复核包含多种不确定情况，不能直接叫侧立。报警、校验、保护和原编号状态继续保留在控制侧。

- K1：开始新一轮双列计数送料。
- K2：暂停/继续，保留计数与空穴队列；空闲手动电机调试语义不变。
- K3：单键清零并停机。
- K4：停止。SW3仍为上停、下启动新一轮。
- SW2：RAW/黑底白色边缘显示；SW1不再选择灰度。精简界面固定显示计数页。

保留完整1000ms保持、每列32任务、各列连续第五空穴报警、一个共用电机。底部用READY、PAUSED、MOTOR RUNNING、ALARM K3 CLEAR、ALARM FIVE EMPTY表示人可读状态。

GPIO仍为右侧J2第1脚/V2，高电平允许运行、低电平停止；继电器5V沿用板上供电，无LED改动。本任务未烧录实板、未操作电机或继电器。速度、停车提前量、实际补料与±1mm仍需实测，不由仿真回执保证。
