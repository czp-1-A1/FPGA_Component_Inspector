# V3 相机黑图修正（2026-10-28）

用户在同一套接线下往返烧录确认：V2有图像，V3背景黑，但Logo、文字及ROI存在。正常待机应显示实时画面；不需要按K1才显示。FPS/CFG只说明部分链路在工作，不能证明相机像素有效。

实际导出两版完整工程的综合网表，对相机配置逻辑进行串行I²C回放（模拟时钟、复位、ACK从机）。正常V2最后五笔写入为 `6c3e0000 / 6c3e0144 / 6c3e0240 / 6c3e0803 / 6c3e0938`；旧V3曝光值相同，增益两字节成为00/00。旧V3提取逻辑的所有消费网均有驱动，外部仅时钟、复位和SDA，排除了切断内部驱动导致错误的情况。

V3为四个运行控制键屏蔽了相机调参键，默认增益40成为固定值。该完整工程综合上下文中，原同步查表在常量地址24下被优化为0，而源码预期应为0338。独立小工程不能复现此异常，因此不能把结论扩大到所有TD常量ROM，也不能称已读回实物传感器寄存器。

修正仅改变生产文件 `SC500GainTbl.v` 的表达方式：将原74项同步表等价改写为三个范围的同步译码，避开ROM推断，保留一拍延迟、全部有效值和无效地址输出0。其余635个冻结工程文件与已交付V3逐SHA相同。当前单排ROI、分类/计数/编号、四键、SW3、停车参数、原引脚及SDC均相同。

验证包括：

- 全部128地址、两种复位脚电平、正反地址顺序，与保留的原始查表逐项比较；固定地址24也必须输出0338。
- 真实I²C引擎的RTL回放，两次复位，每次126笔写入，全序列匹配正常V2，曝光1092/增益40/WB100/100。
- 修正完整工程实际综合网表的相机逻辑305单元，驱动闭合检查通过；两次复位全部126笔串行写入匹配正常V2。
- 相同串行期望用于旧V3，在第125笔明确失败（actual `6c3e0800` / expected `6c3e0803`）；保留失败日志，不计为PASS。
- 原V3选定17项测试仅在每项实际编译输入SHA均与修正版相同时复用；这些测试不包含相机初始化，不能单独证明此次修复。新bit必须另做完整布局布线及严格时序/资源/CDC/引脚审计。
