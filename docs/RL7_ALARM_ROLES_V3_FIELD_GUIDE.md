# RL7 AlarmRoles V3 联调说明

版本：R22_RL7_Demo_AlarmRoles_V3_20261101.bit。基于上一轮UIOpt V2，Git 83674658；原V2和更早版本保留，可直接烧回。完整发布包包含源码、测试、构建报告和FIELD_ANALYSIS.md；最终资源、时序及SHA-256以RELEASE.json和build/physical_verification.json为准。

## 两项变化

- 有效的第5个连续全局EMPTY不再被补件站故障挡住，锁存五连报警、停机并驱动原蜂鸣器。只统计本RUN严格连续的事件编号，同一穴位重复画面不会重复计数；有件/器件复核打断空穴连续段。重复/跳号/错误RUN不会凑成五连。
- 演示界面过滤非器件和偏离教学器件行的未知小轮廓，避免全空穴时上方定位孔被写成“待复核”。器件行中心仍为Y320，未知轮廓标签容差±16像素。真正kind2正常/复核器件、kind3空穴的显示和全部原计数输入保持不变。

没有修改识别阈值、计数编号、停车窗口72..232/目标152/提前32、完整1秒保持、相机、延迟测量、字库或引脚。该版本解决报警与标签问题；背面/复核波动及冷启动问题仍按用户要求暂缓。若定位孔真的进入有件/复核/空穴统计，需进一步提供该场景；标签过滤不能代替分类修复。

## 接线与按键

继电器：右侧J2第1脚V2；继电器5V仍由板子供电，原高电平直触发接线保持。蜂鸣器：C12/O_buzzer_n/LVCMOS33，低有效；100MHz时钟下2kHz，响200ms/停300ms，复位静音。无LED显示。

K1开启新RUN并计数；K2暂停/继续当前自动流程并保留队列，待机时可手动电机启停；K3单键清零、停止、解除报警并静音；K4停止且保留结果。SW3上停、下开启新RUN。五连ALARM期间K2/K4不能使电机重新运行，K3或明确K1新RUN才解除报警。新RUN之前保持计数区域上游起步、补件区无未编号的旧料。

编号监视复用已有的全局有效编号前缀；标签角色在帧开始时与候选一并锁存，避免逐像素重复计算。首轮物理构建在一小时内未收敛而超时，没有生成bit；第二轮采用上述等价简化，重新执行本轮全部检查。

## 上板复测

1. K3清零，再K1开启新一轮。先用整排5个空穴，旁边不放有件，定位孔位于器件穴位上方；整段保持速度不变。
2. 第5个完成计数时应出现红色“ALARM 5 EMPTY”，电机停止，蜂鸣器按200ms/300ms循环。K2不能绕过；K3解除并静音。
3. 测单空穴、三连空穴的停靠/保持1秒/继续送料，再测有件及真正器件复核标签。若只有圆孔标签还在、但复核统计为0，与圆孔真的进入统计是两种情况，反馈时区分。

本次助手没有烧录、接线或驱动实际电机；实板通过情况由本轮录像确认。
