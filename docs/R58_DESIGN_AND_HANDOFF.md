# R58 蜂鸣器与采集到显示延迟：设计及交接

基于已发布 R57 源码提交 `02b18c34d5a723a5de2f17496705dec524b52be3`。这是设计说明，最终构建验收以交付包的验证回执为准；实板验收仍为 **HUMAN_PENDING**。

## 操作

- 屏幕版本为 **INSPECT D3 R58**。
- 板载蜂鸣器为 **C12 / O_buzzer_n / LVCMOS33 / 低有效**；按参考板说明接通 **SW5** 的蜂鸣器连接。
- 任一列触发原有连续五个有效空穴报警后，共用电机停止，蜂鸣器以 **2 kHz 方波、响 200 ms / 停 300 ms** 循环。
- K3 清零或明确的新 RUN 清除报警；K2 暂停/继续和 K4 停止保留已锁存报警。解除后静音，再次报警从新的响声周期开始。
- 五连依据同一 RUN 内按编号顺序确认的空穴事件；同一穴位的重复画面、累计空穴数、队列长度均不能凑成五连。有件事件打断连续空穴段。

## 右上角显示

| 字段 | 含义 | 例子 |
|---|---|---|
| LAT | 当前显示帧的采集 SOF 到本次 HDMI 输出首个有效像素的时间 | `0041.4ms` = 41.4 ms |
| LAG | 最新进入处理域的采集来源号减去当前显示图像的来源号 | `002f` = 来源号相差 2 帧 |
| SRC | 当前显示图像的 32 位采集来源序号，完整十位十进制 | `0000070000` |

LAT/LAG 用蓝色、SRC 用粉色，均为 **16×32** 的双倍 ASCII 字号；位于 1280×720 画面右上方 x896～1263、y8～71，不占用两列统计和底部空穴编号区。字形复用原 8×16 ASCII ROM，中文仍为 R57 的 16×16。

SRC 是内部视频来源编号，在原始采集 SOF 事务进入处理域时分配，包含收到的坏帧/取消帧，与计数 RUN、穴位编号、DDR 槽号及 HDMI 刷新次数不同。K3 计数清零不会将采集来源序号清零。LAG 不是丢帧数，也不用于通过 FPS 换算毫秒。

相机帧被重复显示时，SRC 保持，LAT 每次刷新重新测量并增大。LAG 为 0 时仍可有采集、处理和扫描延迟。没有匹配标签、首像素读出无效、未来来源/时间、超过 6553.5 ms 的陈旧帧显示横线，不能把无效数据显示成 0 ms。像素时钟持续运行时，过期图像保持失效，避免 32 位微秒计数整圈回绕后重新显示成新鲜图像。

## 测量口径

起点 t0 是 FPGA 接收端解码的 RAW10 SOF；终点 t1 是同一图像经 OSD 后送入 HDMI 发射器输入的首个有效像素。测量包括起点之后的传感器读出、ISP、帧缓存、等待读出/扫描和 OSD 流水。

它不包括 SOF 之前的曝光部分、HDMI 输入之后的串行化/外部链路、显示器内部处理及面板响应。因此 LAT 是数字视频链路的采集到输出测量，不能作为光到光延迟或识别算法单独执行时间。时基步长 1 µs、显示步长 0.1 ms，仍有时钟频率、量化和跨域采样误差；没有纳秒精度承诺。

100 MHz 自由运行时基生成寄存的 Gray 微秒计数，分别经 CSI 和像素域两级同步。采集戳通过原 128 位有序处理桥 SOF 头中的空闲 33 位传输，不增加逐像素宽度。该修改使桥内实际有效位增加，综合使用额外一块 ERAM；没有新增整帧缓存。

```text
RAW SOF 锁定时间
  → 原处理桥 SOF 头：valid + timestamp_us
  → 处理域分配 source_frame_id，形成 65 位采集元组
  → ISP 输出帧开始冻结元组并绑定 writer_epoch
  → 完整像素发布：同槽号、同 epoch 的采集元组
  → 读出选帧：像素槽、分类元数据、采集元组同时锁存
  → 原 active-frame 邮箱一起跨到像素域
  → 实际 OSD 输出首 DE 锁存 t1，48 拍串行计算及十进制转换
  → 第 8 行开始显示大字
```

分类结果迟到只补充原有分类元数据，不能改写图像来源或采集时间。时间标签不依赖识别 ready 才生成；完整图像发布也不因计时标签而等待分类。

## 从参考包学习的要点

参考包的完整旧顶层、ISP、OSD 和单列工程没有覆盖 R57。采用了同板蜂鸣器电气参数、共同时基与 Gray 同步、SOF 标签及完整帧所有权的设计思路；新增了目标 R57 链路测试。

重点防止：将五帧误当五穴、用第五次的一拍脉冲代替报警锁存、局部故障屏蔽同拍五连、跨域拼接不一致元组、ISP 同拍采到上一帧标签、分类迟到改写图像来源、槽位复用继承旧时间、重复画面延迟冻结、超时/未来数据显示成 0 ms、时间整圈回绕使旧图复活、字体裁切，以及把另一工程的通过回执当作本工程验收。

新收到的 SOF 使用原有注册 CSI/RAW 解码路径；恢复时钟后新帧包至少经过四个接收时钟边沿到达 ISP 头采样，时间同步为两级。源级审查及本版完整 RAW 时钟停启测试均附带记录；这不替代传感器实板时序验证。

## 验证和实板验收

本版最终源码对应 25 项 RTL 验证（5 项输入字节未变化的本轮测试结果保留，受影响及新增的 20 项重新执行），另有 560640 个独立文字区 RGB 比对、第二列 112 个字形行检查。包括真实 100 MHz 下 50000000 周期蜂鸣器节拍、五连与局部故障碰撞、原 13 项计数停车回归、两帧完整 1920×1080 RAW、13 次实际 DDR/FIFO/相位/OSD 显示帧的独立计时、取消/重复/迟到分类/槽位复用/欠载/恢复/复位、时间及来源号回绕、旧界面像素兼容。

物理验收应要求最终 **Routed / Both Slow and Fast / setup 与 hold 非负 / 两项 TNS 均 0**；核查原有约束和精确 9 条已编译移除的显示路径约束，并核查 64 条新时间 Gray 位及两级连接、C12 注册输出和双列报警。布局阶段资源或时序不能替代最终回执。

烧录后人工验收：先确认图像和 R58 标记，再让两列同时正常计数并核对独立编号/空穴号；制造同一列五个连续空穴，确认停机与响停周期；测试 K2/K4 保留报警、K3 清除、新 RUN 重新开始。观察 LAT/LAG/SRC 随新帧及重复帧变化，检查右上角与两列统计均不裁切。参考预览是 RTL 仿真图，不能当作实板照片；本任务没有操作板卡、电机或继电器。
