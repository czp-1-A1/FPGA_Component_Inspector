# R22 左补件 V3：按键操作与停车标定

本版继电器仍接右侧 J2 第1脚（V2），板载5V供模块，3.3V高电平吸合。沿用原引脚和显示，无新增LED。启动后看屏幕右上 **RL3**，提前量显示 **A020**（十六进制32像素）。原COUNT R22标题继续代表识别算法底座。

## 按键

| 操作 | 作用 |
|---|---|
| K1 短按一次 | 启动新一轮自动计数和送料；重新编号，同时重置上一轮队列与故障。不用先K3清零，也不用操作SW3。 |
| K2 短按一次，再按一次 | 自动运行中：暂停／继续同一轮，保留计数、编号和待处理空穴。上电待机中：手动电机运行／暂停，用于送料和放置试样；K1进入自动。 |
| K3 短按一次 | 停电机并清零计数、编号、队列和故障；不用组合键，不用长按。 |
| K4 短按一次 | 停止本轮送料，保留屏幕结果；K1重新开始。K4后可用K2手动运行／暂停。 |
| SW3 上拨，再下拨 | 上拨停止，下拨启动新一轮；每次下拨均可重开，不再因为旧队列要求K3+K4。 |

按键有20ms消抖，按住只执行一次，松开后才能下一次。烧录／复位后不自动启动；上电一直按住的键要先松开再按。原四键曝光、增益、白平衡操作在本版让位给以上功能，防止启动/清零时改变图像参数；默认曝光1092、增益40保持。

**K2是暂停／继续，K1和SW3下拨是新一轮。** 新一轮明确结束上一轮记录和未处置队列，旧空穴需要人工核对；故障本身不会自动丢弃队列或重新启动。K2不能绕过真正的定位、图像或编号故障；S4故障时处理现场、重新放好试样后按K1。

暂停时相机继续取样和检查编号；15秒到站等待、停车等待计时暂停。若暂停发生在合格保持阶段，恢复后重新确认位置，并完成完整1秒保持。不会把暂停时间算作补件完成。手动搬动载带、遮挡或图像中断仍可能使关联失效并停止。

## 开始一轮

送料方向为屏幕从右往左。自动计数线X640，左站二次编号线X256，停车目标X160，初始提前量32、触发线X192，合格窗口X152～168。以上全为1280×720处理图像的像素，尚未换算为毫米。

新一轮须从计数线左边和补件区没有未编号载带的状态开始，首穴先放在右侧约X800，给方向识别留出行程。K1或SW3新开时会先核对这项；如左侧已有旧料，报FC并保持停止，不能靠复位编号把左右两站的穴位强行配对。要继续同一批料请用K2；要重做试验可K4停止，再用K2手动送料调整位置，最后K4停止、K1开始。

启动后应为S5→S1，空穴进入左站后V1/X显示实际位置，S2停车确认，S3合格保持，完整1秒后S1恢复。S6表示人工暂停，S7表示手动电机运行。S4和F码表示故障；保留完整状态行供分析。

## 新视频的实际原因

视频1c37c718…共9秒、30fps。约3.2秒为S2 F0 Q01 N001 X0AB（171），约3.4秒稳定为X08F（143），约4.4秒进入S4 F8。目标T0A0是160，合格范围152～168，因此143不合格；1.2秒停车等待超时后保护停止。没有进入S3，不能称作保持1秒失败。当前位置和编号仍在连续更新，此证据不指向继电器未断开或V2那次F6丢位置。

本版提前量16→32，是根据这一次稳定停偏17像素给出的标定初值，窗口和完整1秒保持未放宽。171→143是相机实测位置变化，包含图像处理/显示滞后及机械滑行，不能把它直接当成继电器独立延迟或纯机械制动距离。

## 请采集的下一组数据

1. 同一机位、焦距、载带、旋钮速度先做5次。录像保持完整RL3状态行及空穴可见，停车后继续拍至少3秒。每次从右侧重新摆入相同试样，按K1开始，不必K3清零。
2. 记录每次停止后稳定X，是否S3→S1，以及有无F码。若需另一个速度，另做一组并说明旋钮档位，组内保持速度；运行中临时调速的数据单列，不能混在一起标定。
3. 另外分别验证：K2暂停后计数/编号不清零，再按继续；K3一次清零；连续6次SW3上停下开，不先清零。
4. 最后在载带平面放尺子／已知间距标定像素每毫米，再统计实际中心误差，才能判断±1毫米。显示器拍摄的像素尺寸不能直接当实际毫米。

调参关系（左行）：新提前量约等于旧提前量 + (160 - 停稳X)。例如本视频为16+(160-143)=33，先取32作试测。它只是同一速度附近的初步关系，采样相位、继电器动作、载荷、电池和调速会影响结果；不能保证一个固定提前量覆盖所有速度。停得太靠右（X>168）需减小提前量，停得太靠左（X<152）需增大提前量。当前固定停车控制还没有速度自适应和反向纠偏。

先空跑停车→确认→保持→恢复。此版没有吸嘴控制／补件完成握手；停住期间填入元件或遮挡会改变原空穴关联，须另做补件动作的集成，不能视为已经验证。
