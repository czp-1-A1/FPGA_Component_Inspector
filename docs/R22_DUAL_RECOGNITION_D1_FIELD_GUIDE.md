## 两个检测区

坐标为处理画面的 **1280×720 像素**，不是显示器拍照坐标，也不是毫米。范围采用左闭右开。

| 区域 | X | Y | 用途 |
|---|---|---|---|
| ROI1，上方 | 400 ≤ X < 880 | 240 ≤ Y < 400 | 第一条料道识别 |
| ROI2，下方 | 400 ≤ X < 880 | 432 ≤ Y < 600 | 第二条料道识别 |

这两个框恢复原上下布局。请将两条料带的元件主体分别放在各自框内；两框之间留有间隔。原来左侧补件位置已不再占用 ROI2。本次不扩展到未知封装，仍使用已有白色 3528 配方和当前 R22 判据；不同封装需另行标定。

## 电机与按键

使用现有接线：**板右侧 J2 第 1 脚，FPGA V2，高电平允许运行**。继电器继续由已确认的板载 5V 供电，无新增 LED 引脚；原 `pin.adc` 不变。

| 操作 | 本版行为 |
|---|---|
| 上电 / 复位 | 电机停止，识别画面自动运行 |
| K1 | 电机运行，仅手动送料 |
| K2 | 运行 / 暂停切换；停止状态下按也可开始送料 |
| K3 或 K4 | 电机停止；不需要组合键 |
| SW3 上拨 | 停止 |
| SW3 上拨后下拨 | 运行；上电就放在下方不会自行启动 |

K1/K2 不会启动计数或自动停车；识别不依赖电机是否运行。K3 在本版没有可清的计数账本，作用为停止。按钮消抖及按住不重复触发保留。按键不调曝光、增益或白平衡。

## 本次验证与实板复测

完整 TD V6.2.168116 构建：637 份冻结源、105 项硬件依赖。实际布线资源：Slice **16299/21216（76.82%）**，ERAM **100/108**，DSP **26/40**，PLL **5/6**。建立裕量 SWNS **+0.107ns**，保持裕量 HWNS **+0.020ns**，两项总负裕量为 0。

46 项有效最大延迟约束全部命中、无忽略；20 条实际 Gray 跨域路径、6 组手动控制/电机状态邮箱约束、四键/SW3 同步和 V2 输出检查通过。独立识别 SDC 仅去掉未实例化计数结果邮箱的 3 条约束；原 SDC 保留。计数与停车模块没有实例化。

软件检查涵盖上下区真实 RGB 有件/空穴、独立空区、区外/送料孔排除、取消后恢复，两个完整 OSD 栅格、按键/实际电机寄存器代码、RAW10→ISP→DDR→显示帧对齐，以及实际综合网表相机启动 I2C。相机黑图修复保留。具体新运行回执以发布包 `VERIFICATION.json` 为准。

这些是仿真和布线结果，尚未由本版实板图像验收。烧录后先保持电机停止，确认实时画面和 D1 标识，再分别放上/下料带，核对两区有件、单空穴、连续空穴及一条料道空置时的结果。随后用 K1/K2 检查运行暂停。请拍到两个框和版本行；若识别异常，保留原曝光、镜头距离与料带位置以便对照。
