# R22识别＋自动空穴停车联调版

基线：`origin/r22-local-edge-20261027`，提交 `a1cceaa`。开发分支 `codex/r22-relay-v1`，工作目录 `D:/CodexWork/FPGA_R22_Relay_20261027`。保留原R22局部Sobel/灰度识别、计数、编号、中文和Logo；合并版不加独立测试LED。

**本版是需现场标定的自动停车联调版。** 自动逻辑已接入真实编号和新帧实测位置；±1mm尚未标定/上板验收。初始参数是处理图1280×720中的像素，不能拿显示器照片上的像素或1920×1080输入坐标直接替代。本版不驱动吸嘴、不执行补件、不判“已修复”。

## 接线与操作

用户确认继电器由开发板5V供电：右J2第11脚5V→模块DC+；第12脚GND→DC−；第1脚V2→IN1。S1 COM-HIGH，3.3V高=允许送料，0V=停止；用户已报告3.3V能够触发。第2路不用。旧IN1到5V的额外上拉不保留，不加NPN。

电机仍使用原四节AA电池与调速板：电池正极→COM1，NO1→调速板Power+；电池负极→Power−。继电器控制供电来自板子，不把电机改由板子5V供电。方向开关固定为相机图像中的向右送料。

- 上电保持停止；SW3初始向下也不会自动启动。
- **SW3向上准备/停止；再向下，沿用原操作开新RUN并允许送料。** 先向上保持约0.1秒再向下，覆盖原按键去抖时间。
- SW4照旧切检测页/计数页；SW1/SW2与K1/K2保持原图像模式、曝光/增益功能，K1不再是独立测试版的电机按钮。
- K3+K4长按1秒仍是原全清，同时关闭继电器并确认清除停车队列。清除前人工核对尚未处置的空穴；SW3上/下不能悄悄丢弃待处理编号。
- 故障后先SW3向上停止、记录画面和目标位置；处理原因并人工核对待处理料段，再全清并开新RUN。没有自动倒带或自动微调。

先确认原R22画面/计数正常，再在原常用速度连接负载。记录继电器吸合/释放时是否伴随屏幕闪断或FPGA重启，这一项用于验收板载5V带负载的实际表现。

## 自动行为

1. 从原计数器接收已编号EMPTY事件，按同一内部RUN保存最多8个待处理ID；重复EMPTY不重复入队。PRESENT/REVIEW不自动入队，历史类别/空号不改写。
2. 队首ID向原关联器查询当前位置。坐标只来自该ID在新源帧中的真实观测，整帧关联/运动检查通过后才发布；预测的候选保留坐标、显示排序和旧事件帧不能作为停车位置。
3. 正向目标达到触发线即拉低V2。若已经越过停车允许窗口、图像异常、反向、目标过期或队列溢出，停止并显示故障。
4. 断电后继续看目标新帧。至少3个实测位置落在允许窗口且相邻位移很小时进入保持；在此之前不开始1秒计时。
5. 保持期间继续核对同一编号的新位置；明显漂移或失去新观测就保持停止并报错。连续合格满1秒后记一次“定位保持完成”，移出队首并恢复送料，处理下一空穴。

## 初始参数及屏幕

| 项目 | 初值 | 含义 |
|---|---:|---|
| 计数线 | X=640 | 原R22不变 |
| 停车目标线 | X=760 | 后续对准实际补料位置 |
| 提前量 | 24px | 当前触发X=736，需现场实测修改 |
| 允许位置窗口 | 目标±8px | 不是已验证的±1mm |
| 静止位移阈值 | 2px | 相邻观测及保持锚点的X/Y约束 |
| 稳定观测 | 至少3帧 | 仅新源帧、同RUN/ID |
| 合格保持 | 1000ms | 100MHz完整100,000,000周期验证 |
| 新帧/目标过期 | 150ms | 超时停止 |
| 等待停稳/入窗 | 1200ms | 未合格则保持停止 |

参数入口在 `design_top_wrapper.v` 的 `RELAY_TARGET_X`、`RELAY_ADVANCE_PX`、`RELAY_TOL_PX`，本版修改参数需要重新综合/布线/交付，不支持运行时串口调整。总提前量包括真实图像年龄、算法和继电器/机械停止延迟。

原ROI中新增实线目标线和虚线触发线。上部第三行右侧增加 `RLY S… F… Q… ID… X… T… A…`，**所有数字均为十六进制**：S状态、F故障、Q队列数、ID队首号、X最近实测X、T目标X、A提前量。例：T2F8=760，A018=24，ID008=第8穴。显示使用独立稳定邮箱，仅供观察，不反馈到控制；未取得新目标观测时X可能保留历史值，控制会按新鲜度另行判断。

S：0停止/未启动，1送料，2等待停稳入窗，3合格保持，4故障停止。

| F | 原因/处置线索 |
|---|---|
| 0 | 无故障 |
| 1 | 坏帧、计数失锁/CHECK/DONE，检查原R22状态与图像 |
| 2 | 缺少新有效图像 |
| 3 | 检测到向左/反向，本版仅向右 |
| 4 | 事件内部RUN不匹配 |
| 5 | 8个待处理ID队列已满；核对速度、连续空穴和待处理料段 |
| 6 | 队首目标缺少新实测位置 |
| 7 | 目标被看到时已超出允许停车位置 |
| 8 | 停车后1200ms仍未稳定进入窗口，优先调整触发提前量/目标位置 |
| 9 | 保持期间超出窗口或相对锚点明显漂移 |
| A | 新开RUN时仍有未处理队列，先人工核对并显式全清 |
| B | 参数不合法或没有送料许可 |

## 第一轮现场回传

保持原机位、曝光、常用速度，先用一个已知空穴确认：编号是否正确、是否到虚线后断电、最终X及F代码、有没有进入S3并自动恢复。若提前停在窗口外，F8是预期的保护反馈，记录最终X后调整提前量再生成下一版，不放宽±1mm目标来“通过”。

随后在同一运动平面用固定毫米尺标定处理像素/毫米，标明实际补料中心。以固定视频或相机原始截图给出10次停车结果/漂移，最终用独立30次实际偏差及1秒保持记录验收；连续空穴、首末、重启、断流、反向和板载供电回归分别验证。
