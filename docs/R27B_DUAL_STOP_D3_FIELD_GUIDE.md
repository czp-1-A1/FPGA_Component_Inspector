# R27B 两列计数与补件停车 D3

本说明对应 R27B 双列计数与双列停车合并源码。可烧录版本、来源、资源、时序和 SHA 以发布回执为准；实板验收另按下方顺序执行。

## 保留的功能和处理方式

主识别/计数采用队友已实板确认成功的 R27B。两列独立编号、总数、有件/空穴/复核统计、空穴列表和源帧绑定保留。主计数原算法和四候选输入保持；只读观察副本与原件做字节恢复证明，并在传送仿真逐拍比较全部1197个公开位。

两列各有自己的全局编号待处理队列、实测位置和1000ms保持状态，共用电机。任何一列停车时，两列载带都会停止；同次停止中已到位的两列任务可分别完成保持。两个控制器都允许送料后，电机才恢复。单列连续五个真实编号空穴锁定报警；上下列各四个不会合并成五个。有件打断该列连续空穴序列。

位置关联使用同一帧的真实 EMPTY 候选，以及主计数器给出的编号、真实越线坐标和实测移动信息。预测只帮助寻找目标，不能直接完成停车。短暂漏检可重新关联；持续缺失/类别不符/编号不确定时保留故障和待处理任务，不能用旧坐标假装完成。

## 布局和方向

- 屏幕送料方向：右向左。
- 上列计数区：X400～879、Y240～399；下列：X400～879、Y432～599。
- 左区内部定位范围：每列X64～399，与各列对应Y范围一致。
- 两个黄色补件验收窗：X72～232，目标中心X152，提前触发X184。
- 两个验收窗沿用当前放宽范围；不代表已实现±1毫米，也未实际安装或验证吸嘴补件。

## 按键

| 操作 | 行为 |
|---|---|
| K1 | 开始新一轮双列计数与自动停车；无需先K3清零 |
| K2（自动运行中） | 暂停/继续当前自动流程，保留计数和待处理空穴 |
| K2（空闲时） | 进入电机调试运行，再按暂停；报警仍禁止电机运行 |
| K3 | 单键清零并停止，解除五空报警 |
| K4 | 停止运行 |
| SW3上、再下 | 停止、开始新一轮；保持原兼容操作 |

上电不自动运行。沿用已验证的右侧J2第1脚V2控制和板载5V供电接线，集成版无LED。V2高运行、低停止的实际控制方式保持；不要按旧C18/J1说明改接。GPIO是控制信号，继电器的5V电源来自板卡电源脚。

## 实板验收顺序

1. 烧录后先确认正常实时画面，上下两列框/计数与两个左侧黄窗显示正确。
2. K1启动，先测只有上列一个空穴，再测只有下列一个空穴：各自编号停车，停稳保持完整1秒后恢复。
3. 测上下交错空穴、上下同时空穴和每列三连，观察当前编号逐个完成、队列减少并继续送料。
4. 测K2暂停/继续和K1直接重开一轮，确认不需要先组合清零或反复拨SW3。
5. 上列五连、下列五连分别测试；只有达到五连的列报警，两列共用电机停止，K3单键解除。两列各四空不应合并报警。

录像保留完整的顶部双列统计及右上L1/L2状态、补件黄窗；出现故障后先继续拍2～3秒再清零。发回完整过程用于分析，不需要自行解码状态。
